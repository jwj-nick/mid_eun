# Math Story for Mid 1

> 중학교 1학년 딸을 위한, 이야기로 배우는 수학 프로젝트.
> 아빠와 딸이 AI와 함께 만들어가는 살아있는 수학 교양서.

## 프로젝트 한 줄

중1 교과과정의 모든 단원을, 그 개념을 만든/사용한 실존 인물의 이야기로 다시 쓰고, 딸이 그 이야기를 자기 언어로 다시 쓰면서 개념을 체화하는 프로젝트.

## 왜 만드는가

- **수학을 싫어하지 않게** — 점점 어려워질 수학을 끝까지 따라갈 수 있는 정서적 토대.
- **개념을 진짜 이해하게** — "들어봤다" 수준이 아닌, 자기 언어로 설명할 수 있는 수준.
- **AI로 직접 만드는 경험** — 딸이 "이런 걸 내가 만들 수 있구나"를 체득.
- **학교 성적은 부수적** — 중간 이상이면 충분. 핵심 목표가 아님.

## 우선순위

1. **(a) 수학 흥미 + 개념 이해 + 교양** ← 최우선
2. **(c) AI로 직접 만드는 경험**
3. **(b) 학교 성적 중상위 유지** ← 부수적

## 학습자 프로필 요약

- 중1, 국어/영어 강세, 수학 중하위
- 글쓰기에 강점, 감성적·공감 능력 높음 → **서사 기반 학습이 본질적으로 맞는 타입**
- 개념은 알면 풀 수 있으나 속도가 안 나고 오답률 높음 (절차적 유창성 부족 가능성)
- 가용 시간: 주 4~5일 × 1시간

## 진행 방식

1단계 — 아빠와 AI가 1차 결과물 제작 (딸은 사용자)
2단계 — 딸이 사용하면서 "어떻게 만들었지?" 호기심 → 아빠가 역추적해서 설명
3단계 — 딸이 Claude Code에 직접 채팅하며 새 기능 추가 (아빠 도움)

## 도구

- Claude Code, Local directory, GitHub
- Markdown 중심 (확장 시 web/app 형태 검토)

## 두 개의 핵심 축

이 프로젝트는 두 개의 평행한 트랙으로 진행됩니다.

**축 1: 인물 서사 기반 단원 학습 — "수학의 사람들"**
중1 8개 단원을 인물 이야기로 다시 쓰고, 딸이 자기 글로 정리.

**축 2: 수학 언어 자체에 대한 메타 학습 — "수학 언어 사용 설명서"**
문자·기호·관습이 어떻게 작동하는지를 단원과 평행하게 익힘.
(추가 계기: 딸이 `y=a/x, a=-2`에서 식을 다시 쓰지 못한 관찰 — Round 6 참고)
