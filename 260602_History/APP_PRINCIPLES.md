# APP PRINCIPLES — 세계대전 이야기 학습 앱 설계 원칙

> 사이드바형 단일 SPA. 대상: 중1 여학생(감성적·내성적, 국어/영어 강세, 역사 첫 입문).
> 모든 섹션 제작은 이 파일을 준수한다.

---

## 핵심 철학

### 1. 이야기가 먼저, 사실은 그 안에
연표·용어를 먼저 들이밀지 않는다. **한 사람의 이야기·장면·감정**으로 들어가고, 사실은 그 맥락 안에서 자연스럽게 만난다. (안네의 일기가 전체 앱의 정서적 입구인 이유.)

### 2. 따뜻하고 말 거는 톤
"~했어요", "함께 따라가 볼까요?", "여기서 잠깐 — 왜 그랬을까요?" 같은 친근한 2인칭. 어려운 단어는 첫 등장 시 괄호로 한 줄 풀이.

### 3. 빈칸을 남겨라
모든 섹션 끝에 "내 생각 적어보기 / 가장 마음에 남은 장면" 같은 **딸이 채울 칸**. 탐구학습 과제로 바로 옮겨 쓸 수 있게.

### 4. 수위 조절
전쟁의 잔혹함·정치적 논쟁은 중1이 감당할 수준으로. 사실은 숨기지 않되, 자극적 묘사·이미지는 피하고 "사람들의 마음"에 초점.

## 공통 UI 원칙

- **단일 HTML 파일** + 필요 시 분리된 콘텐츠(JS 데이터 객체 또는 fetch한 .md). 빌드 없음, CDN만.
- **레이아웃**: 좌측 고정 **사이드바**(섹션 목록) + 우측 콘텐츠 영역. 모바일에선 사이드바가 햄버거로 접힘.
- **사이드바**: 8개 섹션 순서대로. "안네의 일기"는 ⭐ 또는 색 강조로 시각적 중심.
- **반응형**: 데스크톱/태블릿/모바일. 콘텐츠 max-width ~760px, 큰 줄간격.
- **타이포**: 본문 16~18px, 짧은 단락(3~4줄), 넉넉한 여백. 읽는 부담 최소화.
- **진행 표시**: 섹션 내 스크롤 진행 또는 "다음 섹션 →" 버튼.

## 색·비주얼 (여학생 친화, 무겁지 않게)

- 주조색: 따뜻한 톤 (예: 세피아/더스티 로즈 `#C98B8B`, 차분한 네이비 `#34406B`, 크림 배경 `#FBF7F2`).
- 시대 분위기를 색으로 (전쟁기 = 차분·바램, 전후/한국전쟁 = 회복의 온기). 단원별 팔레트는 `10_docs`에 정의.
- **무거운 흑백 전쟁 사진 남용 금지.** 일러스트풍·지도·타임라인·인물 카드 위주.
- 아이콘·이모지는 절제해서 길잡이로만.

## 섹션 구성 템플릿 (8섹션 공통)

각 섹션은 아래 흐름을 따른다. 모두 채울 필요는 없되 순서는 유지:

1. **여는 장면 (Hook)** — 한 인물/한 장면/한 질문으로 시작. 1~2단락.
2. **왜 중요할까** — 이 섹션이 전체 이야기에서 갖는 의미. (큰 그림 연결)
3. **핵심 따라가기** — 3~6개의 "사실 카드". 카드 1개 = 한 가지 사건/개념 + 짧은 설명.
   - 어려운 용어는 카드 안에서 풀이.
   - 가능하면 **타임라인** 또는 **간단한 지도**로 시각화.
4. **연결 고리** — 이전/다음 섹션과 어떻게 이어지는지 한 줄. (전체가 하나의 이야기)
5. **영상으로 보기** — 엄선된 한국/외국 유튜브 1~3개. 각 링크에 "무엇을 볼 수 있나" 한 줄 + 길이.
6. **내 생각 적어보기** — 빈칸 1~2개. (탐구학습 메모용)

## 안네의 일기 섹션 (특별 규칙)

- 전체 앱의 **정서적 심장**. 가장 공들여 만든다.
- 안네라는 한 소녀(딸 또래)의 일상·꿈·두려움에 초점 → "전쟁은 통계가 아니라 사람"임을 느끼게.
- 실제 일기 인용은 **공개된/저작권 안전한 발췌**만, 출처 표기. (확인은 `20_research/`)
- 은신처 구조, 가족·동거인, 발각·이후를 차분히. 결말은 사실대로 전하되 "안네가 남긴 것(일기·기억)"으로 닫는다.
- 딸 활동: "나라면 그 다락방에서 무엇을 적었을까?" 빈칸 → 영상 제작의 씨앗으로 연결 가능.

---

## 유튜브 링크 큐레이션 원칙

- 출처 신뢰도(공영방송·교육채널·검증된 다큐) 우선. `20_research/`에서 한 번 검토 후 등록.
- 중1이 끝까지 볼 만한 길이(가급적 ~10분 내 또는 챕터 안내).
- 한국어 자료 우선, 외국어는 자막 여부 표기.
- 각 링크: 제목 / 채널 / 길이 / "무엇을 볼 수 있나" 한 줄 / (선택) 권장 구간.
- 자극적 썸네일·미검증 채널 배제.

---

## 사실 정확성 원칙

- 콘텐츠 서술의 사실은 `20_research/`에서 1차 확인 후 작성. 날짜·인명·지명 특히 주의.
- 해석이 갈리는 주제(원폭 정당성, 책임 소재 등)는 **"이렇게 보는 시각도, 저렇게 보는 시각도 있어요"**로 균형 있게, 단정 회피.
- 추정/일화는 그렇게 표시.

---

## 검토 체크리스트 (섹션 완성 시)

- [ ] 여는 장면이 사람/장면/질문으로 시작하는가 (연표 나열 아님)
- [ ] 어려운 용어를 첫 등장 시 풀이했는가
- [ ] 핵심 카드 3~6개, 타임라인/지도 시각화 시도했는가
- [ ] 이전/다음 섹션과의 연결 고리 한 줄 있는가
- [ ] 유튜브 링크가 검토·출처표기되었고 "무엇을 볼 수 있나"가 있는가
- [ ] "내 생각 적어보기" 빈칸이 있는가
- [ ] 수위·톤이 중1 여학생에게 적절한가
- [ ] 사이드바에서 이 섹션으로 정상 이동되는가 (모바일 포함)
