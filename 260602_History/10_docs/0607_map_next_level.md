# 0607 — 지도, 다음 레벨 로드맵 (비전·후보·실행·리뷰)

> Nick: **현재 지도 수준에 만족 못함. 비주얼 개선 의지 강함.** 이 문서 = 다음 레벨 후보군 + 실행 + 리뷰 방법.
> 제약은 그대로(바닐라·CDN·키0·공개Pages·중1). 단, "키 없이 어디까지 고급으로 갈 수 있나"를 끝까지 민다.
> 즉시 실행(C)은 별도: `plan/0607_map_C_execution_plan.md`.

## 0. 현재 수준 진단 (왜 부족한가)
- 점(마커) + 점선 polyline뿐 — **정적**. 움직임·시간·방향·드라마가 없다.
- 현대 지도만(OSM) — **시대감/옛 국경** 없음. 질감이 평범.
- 한 장에 다 보여줘 **읽는 순서**가 없다(스토리텔링 부재).

## 1.5 ★지배 원칙 — 도구상자 + 콘텐츠별 선택 (하나의 '기본'은 없다)
> 모든 기법(N1~N9)은 **버려지지 않는 옵션**이다. "기본 티어 하나를 정한다"가 아니라, **콘텐츠 성격에 맞는 방식을 그때그때 고른다.** 아래가 그 선택 가이드.

| 콘텐츠 성격 | 추천 방식 | 이유 |
|---|---|---|
| 한 지역의 전투·봉기 흐름 (동학·국지전) | **T0-A 실측 단계지도** 또는 **B 고지도 연출** | 정확 위치 + 진군 단계 |
| 넓은 다지역 전쟁 (청일·러일·태평양) | **T0-A 광역** 또는 **T2 MapLibre** | 여러 곳·확대해도 선명 |
| 이야기 순서가 핵심 (한 사건을 따라가기) | **T1 스크롤리텔링** | 읽는 순서 = 지도 이동 |
| 전 지구적 구조 (제국↔식민지·냉전·교역) | **T3 글로브** 또는 **D3 흐름** | 전 지구 스케일 임팩트 |
| 영토·세력권 변화 (제국 팽창·분단) | **T2 MapLibre + GeoJSON** | 면적·국경 morph |
| 시대감이 중요한 한 장면 | **B(고지도 위 SVG)** 또는 **N4 고지도 타일** | 분위기·옛 국경 |

→ 따라서 엔진은 **모든 mode를 상비**(아래 §3 통합 `geo` 블록)하고, episode.json에서 콘텐츠별로 `mode`를 골라 쓴다.

## 2. 도구 확보 로드맵 (어느 기법을 언제 '갖출' 것인가 — '기본 선택'이 아님)
- **Tier 0 (지금)**: **C = N1 + N2.** 우금치(SVG)·청일/러일(Leaflet). → 다이나믹의 첫 도약.
- **Tier 1 (다음, 고효과·저비용)**: **N4 고지도 타일**(질감) + **N3 스크롤리텔링**(몰입). 둘 다 키 없이 체감 큰 변화.
- **Tier 2**: **N6 MapLibre**(벡터·고지도풍·3D) — "현 수준 불만"의 근본 해소. 영토 에피소드면 **N5 morph** 결합.
- **Tier 3 (실험)**: **N7 글로브**(제국주의 전 지구 분포), **N8 D3 흐름**(실크로드·교역), **N9 AI 해설**.

## 3. 아키텍처 제안 — 통합 `geo` 블록
- 블록 난립 방지: 단일 `geo` 타입 + `mode`(`battlemap|marchmap|territory|scrolly`) + `engine`(`leaflet|svg|maplibre`).
- 엔진은 mode별 렌더러 1곳에. **데이터(episode.json)만으로 다음 레벨 적용** → 에피소드 무한 확장.
- 자산: PD 베이스맵/타일은 `30_content/<slug>/img/`(출처표기). GeoJSON은 `30_content/geo/`.

## 4. 실행 방법 (공통 파이프라인)
1. **시범 1개 먼저**(항상): 한 사건을 한 mode로 만들어 효과·비용 측정 → 좋으면 엔진 블록화·데이터 확장.
2. **자산 게이트**: PD/CC 확인(파일페이지) → 다운로드 → `file` 실물 → 출처표기. 키 노출 0.
3. **엔진 블록화**: mode 렌더러 + CSS + JS_OK(G1). 신규 플러그인은 CDN·무키만.
4. **데이터 채우기**: 좌표·진격로·국면을 episode.json에.
5. 배포 G3 + 시스템(SCHEMA/PROGRESS/스킬) 갱신.

## 5. 리뷰 방법 (★Nick 요청 — 어떻게 "좋아졌나"를 판정)
- **R1 시각 회귀**: 배포 전 **데스크톱+모바일 스크린샷** 캡처, before/after 나란히. (개선 체감의 1차 증거)
- **R2 멀티 페르소나 audit**(체크리스트):
  - 🗺️ **카토그래퍼**: 좌표·국경·축척 정확? 시대 오류 없나?
  - 👩‍🏫 **교사(중1)**: 한눈에 읽히나? 단계 수·텍스트량 적정? 색맹 안전?
  - 🎨 **디자이너**: 질감·여백·모션 품질(끊김 없나)·브랜드 톤?
  - ⚖️ **역사학자/균형**: 침탈vs저항 균형? 피해 서술? 약소국 관점?
- **R3 성능 게이트**: 모바일 로드·애니 프레임(60fps 근접), Lighthouse, 번들/이미지 용량.
- **R4 기술 게이트**: G0~G3(hist-deploy) + **키 노출 0** grep.
- **R5 딸 사용성**(최종 심판): 흥미↑·이해↑ 실제 반응(T1 피드백). "멋지다/이해된다"가 진짜 KPI.
- **A/B 비교**: 같은 사건을 두 방식으로(예: 우금치 SVG vs Leaflet) 만들어 정함.

## 6. 의사결정 포인트 (다음에 결정)
- Tier 1에서 N3(스크롤리텔링) vs N4(고지도 타일) 우선순위.
- N6 MapLibre 도입 시점(영토 에피소드 등장 때 vs 선제).
- `frontend-design` 플러그인으로 비주얼 폴리시 표준화할지.
