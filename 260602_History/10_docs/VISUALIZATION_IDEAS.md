# 챕터별 시각화 아이디어 (두 에피소드 16챕터)

> 각 페이지(섹션)에 어떤 시각화를 넣으면 좋을지 정리. 블록 타입으로 표기 → 엔진에 재사용 컴포넌트로 추가.
> 상태: ✅적용됨 / 🟡엔진있음·미적용 / 🔧블록 신설 필요.

## 공통 방침 — "지도/이미지는 제대로 된 것만"
- **지도**: ① **실제 지도(Leaflet+OSM, R3 ✅)** = "어디서 일어났나"(현대 지도+마커). ② **공개도메인 역사지도 이미지**(image 블록 🔧) = "그때 국경/세력이 어땠나"(옛 지도 정확). **손그림 금지.**
- **이미지/사진**: 공개도메인(Wikimedia Commons, PD-old/1929년 이전) 또는 공식기관(예: Anne Frank House) 링크만. 출처·라이선스 표기. 다운로드 후 레포에 호스팅.
- 블록 카탈로그: map✅ / quiz✅ / notes✅ / **image🔧** / **compare🔧**(before·after 슬라이더 또는 단계 토글) / **chart🔧**(인라인 SVG 막대·선) / **timeline-i🔧**(인터랙티브 연표) / **gallery🔧**(인물 카드) / **hotspot🔧**(주석 이미지) / **choice🔧**.

## 우선 제안 (다음 라운드 후보)
1. **🔧 image 블록 신설** → 공개도메인 **역사지도**(제국 분포 1900, 아프리카 분할 1914, 유럽 동맹 1914)로 "옛 국경" 정확히. 손그림 불만의 진짜 해법. (Wikimedia PD 소싱→레포 호스팅, 출처표기)
2. **실지도(map✅) 챕터 확대**: 유럽 전선·태평양·인도·아편전쟁·조선 등 ★★★/★★ 섹션에 마커 지도 추가(이미 엔진 있음, 데이터만).
3. **🔧 compare 블록**: 유럽 전선 1942/1945, 한국전쟁 전선 변화, 메이지 전후.
4. **🔧 timeline-i / chart / gallery**: 그다음.

> 진행 원칙: 블록 신설(🔧) 1개 = 한 라운드(엔진+스키마+시범+스킬/audit 갱신). map은 이미 있으니 데이터만 추가하면 즉시 확대 가능.

## 정합성 노트 (0605 — 활성 계획 `plan/0605_replan.md`와 동기화)
이 문서는 **유효**하며 0605 replan과 정합적. 검토에서 나온 보강 3건 반영:
- **안네 섹션(★★★) = 쇼케이스 섹션.** 별도 Stage 대신 블록 누적: 정적 timeline(지금)+hotspot(S1)+지도(S2). hotspot은 **image 블록에 흡수**(별도 블록 안 만듦).
- **chart 승격.** 본문 ★로 흩어진 차트(대공황·사상자·아편·인구)를 정식 Stage(S3)로.
- **이미지 소싱이 실제 병목.** 본문의 "Wikimedia 검색어"는 후보일 뿐 → S1은 **실물 PD 이미지 확보·라이선스 확인부터**, 실패 시 해당 섹션 map으로 폴백.
- Stage 순서: S1 image(+hotspot) → S2 map확대 → S3 chart → S4 compare → S5 people → S6 choice. (timeline-i=후순위, 정적 timeline은 이미 사용 가능)
