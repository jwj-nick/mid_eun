# 인물 도감 업그레이드 — 설계 아이디어

> 현재 `/history/people/`(S6)는 이름·한 줄·왜·그림자 정도로 **내용이 빈약**하다.
> 목표: **사진 + 신뢰할 수 있는 공식 링크 + 다국어 이름·발음 + 클릭하면 깊이 탐구**하는 진짜 '도감'으로.
> 이 문서는 아이디어/설계만. 구현은 별도 Stage로(끝에 단계화 제안).

## 0. 현재 한계
- 이모지 얼굴뿐(실제 인물 사진 없음), 외부에서 더 알아볼 링크 없음.
- 한국어 이름만 — 그 나라 언어/발음/영어 표기가 없어 검색·탐구 진입이 어려움.
- 카드가 종착점(클릭해도 더 들어갈 곳이 없음).

## 1. 업그레이드 목표 (Nick 요청 5가지)
1. **사진** — 가능한 한 실제 초상(라이선스 안전한 것만).
2. **공식·신뢰 링크** — 위키백과(여러 언어)·공식 기관·백과사전.
3. **다국어 이름** — ① 그 나라 언어 원어 표기 ② 실제 발음(한글 근사) ③ 영어권 표기 ④ 한국어(한자음).
4. **클릭 탐구** — 카드를 누르면 상세로 들어가 사진·생애·연표·링크·관련 에피소드까지.
5. 결국 **"한 인물을 깊이 파고드는 작은 위키"** 가 앱 안에 생기는 것.

## 2. 확장 Person 스키마(안)
기존 `{face,name,who,why,quote,shadow}` 에 **추가 필드**(모두 선택, 있으면 상세에 표시):
```jsonc
{
  "slug": "lin-zexu",                         // 상세 라우팅 키(#person/lin-zexu)
  "names": {
    "native": "林則徐",                        // 그 나라 언어 원어
    "roman": "Lín Zéxú",                       // 로마자/병음
    "pronun_ko": "린 쩌쉬",                     // 실제 발음 한글 근사
    "en": "Lin Zexu",                          // 영어권 표기
    "ko": "임칙서",                            // 한국어(한자음)
    "alias": "녹두장군 같은 별칭(선택)"
  },
  "nationality": "청나라(중국)", "lifespan": "1785~1850",
  "portrait": { "src":"img/people/lin-zexu.jpg", "source":"Wikimedia", "license":"PD" },
  "portraitLink": "저작권 사진은 임베드 대신 공식 링크로",   // portrait 없을 때
  "bio": "2~4문단 생애(중1 눈높이)",
  "links": [ { "label":"위키백과(한국어)", "url":"...", "lang":"ko", "type":"wiki" },
             { "label":"공식 기관/백과", "url":"...", "lang":"en", "type":"official" } ],
  "personTimeline": [ {"yr":"1839","t":"아편 몰수·폐기"} ],
  "related": [ { "ep":"imperialism", "section":"opium-china", "label":"아편전쟁" } ],  // 앱 내 역링크
  "reflect": "이 인물에게 편지를 쓴다면? (S0 편지 장치 연계)"
}
```
> 기존 카드(요약)는 그대로, **추가 필드는 상세 화면에서만** 펼친다 → 색인은 가볍게, 탐구는 깊게.

## 4. 사진 라이선스 정책 (★중요 — 손그림 금지와 같은 원칙)
- **임베드 가능(PD)**: 19세기·20세기 초 인물 초상은 대개 퍼블릭 도메인.
  - 임칙서·이토 히로부미·전봉준(1895 압송 사진)·락슈미바이(당대 회화) → **PD 초상 확보 가능성 높음**(Wikimedia 파일페이지에서 PD 확인 후 다운로드).
- **임베드 금지/주의**:
  - **안네 프랑크 사진 = 저작권 보호**(Anne Frank Fonds). 임베드하지 말고 **공식 anne frank house 링크**로. 카드엔 📔 상징 유지.
  - **명성황후 사진 = 진위 논쟁**(현존 사진이 본인인지 학계 이견). 단정적 사진 대신 설명 + 공식 한국학 링크.
- 절차: hist-research '이미지 에이전트'로 **파일페이지 라이선스·저자·직접 URL 검증 → 다운로드 → `30_content/people/img/` 호스팅 → 출처 표기**. (S1 image와 동일 파이프라인)

## 5. 신뢰할 수 있는 링크 출처 가이드
- **위키백과**: 한국어/영어/그 나라 언어 3종(언어별로 정보량·관점이 달라 탐구에 좋음).
- **백과·기관**:
  - 한국 인물 → **한국민족문화대백과사전**(encykorea.aks.ac.kr), **우리역사넷**(contents.history.go.kr).
  - 안네 → **Anne Frank House**(annefrank.org, 공식·교육자료 풍부).
  - 일반 → **Encyclopædia Britannica**(britannica.com).
- 링크엔 언어 배지(ko/en/원어)와 종류(위키/공식/백과) 표기. 외부링크는 `target=_blank rel=noopener`.

## 6. UX — 클릭 탐구 (앱 안에서 깊이)
- 색인(`/history/people/`)의 카드 클릭 → **상세 뷰**.
- 구현 선택지:
  - **(A) 해시 라우팅 상세**(권장): 같은 페이지에서 `#person/<slug>` → 상세 패널 표시(뒤로가기로 색인). 단일 파일 유지, 빠름.
  - (B) 인물별 페이지 `/history/people/<slug>/` — 깔끔하나 파일 수↑.
- 상세 구성: 큰 사진(or 상징) · 다국어 이름 블록 · 국적/생몰 · 생애(bio) · 개인 연표 · **관련 에피소드 섹션 역링크**(앱 내 순환 탐구!) · 공식 링크 목록 · 빛과 그림자 · "이 인물에게 편지"(S0 연계).
- **관련 에피소드 역링크**가 핵심: 도감 ↔ 에피소드를 오가며 탐구하는 순환 구조.

## 7. 빌드/엔진 영향
- `build_people.py` 확장: 확장 필드 읽어 **색인(요약) + 상세(해시 라우팅)** 동시 생성. 사진 자산 복사(`30_content/people/img/`).
- 또는 인물 데이터를 에피소드에서 분리해 **`30_content/people/people.json`** 단일 소스로 승격(에피소드 people[]는 요약만, 상세는 people.json) — 유지보수 ↑. (검토 필요)
- 접근성: 사진 alt, 링크 언어 표기, 키보드 포커스.

## 8. 단계화 제안 (다음 Stage 후보)
- **P1 데이터 채우기(리서치)**: 6인물의 다국어 이름·생몰·PD 사진 확보·신뢰 링크 수집(hist-research 이미지·인물 에이전트 병렬). ← 병목이자 핵심.
- **P2 스키마·엔진**: 확장 Person 스키마 확정 + build_people.py 상세(해시 라우팅) 렌더 + 사진 파이프라인.
- **P3 역링크·연계**: 관련 에피소드 ↔ 도감 순환 링크, "편지" 연계.
- 인물을 늘리며(안중근·미프 히스·간디 등) 도감이 에피소드와 함께 성장.
