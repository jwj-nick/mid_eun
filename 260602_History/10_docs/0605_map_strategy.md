# 지도 전략 (Map Strategy) — 내부 SSOT

> 그동안 지도 관련 생각이 여러 파일에 흩어져 있어 한 장으로 모은다.
> 참고(외부): `10_docs/0605_ext_history-app-map-visualization.md` (Nick이 claude.ai에서 조사). 이 문서는 그 외부 문서를 **우리 제약에 맞게 취사선택**한 결론이다.

## 0. 우리 제약 (이게 모든 선택을 지배한다)
- **바닐라 HTML/CSS/JS, 빌드 없음, CDN만.** (다른 앱들과 동일 스택)
- **공개 GitHub Pages** = 클라이언트에 비밀키를 둘 수 없다.
- **중1 딸** = 가짜 정밀함보다 "이해되는 정직한" 시각화.
- **데이터↔엔진 분리** = 엔진/디자인 1곳, 콘텐츠는 episode.json.

## 1. 에피소드 4유형 분류 (외부 문서 채택 ✅)
마스터플랜의 "거꾸로 올라가는 세계사"와 맞물린다.

| Type | 성격 | 예시(미래 에피소드) | 표현 | 우리 수단 |
|---|---|---|---|---|
| **A 영토/세력권** | 면적·국경 변화 | 몽골제국, 로마, 1900 제국 분포 | 영역 채색 | GeoJSON 폴리곤 / **PD 역사지도 image** |
| **B 전쟁/전투** | 진격로·전선 | 노르망디, 임진왜란, 태평양 | 마커+경로선 | **Leaflet 마커+polyline ✅(보유)** |
| **C 교역/이동** | 경로·흐름 | 실크로드, 대항해 | 선 경로 | Leaflet polyline |
| **D 문화/종교 전파** | 확산 | 불교·이슬람 | 확산 단계 | Leaflet 단계 토글 |

→ 현재 두 에피소드는 전부 **Type B(장소·전선)**. 이미 보유한 Leaflet 마커 지도로 충분.

## 2. 기술 스택 결정 (외부 제안 vs 우리 결론)
| 항목 | 외부 문서 제안 | 우리 결론 | 이유 |
|---|---|---|---|
| 엔진 | Mapbox GL JS (Type A,B) | **Leaflet 단일 ✅** | Mapbox=토큰(공개레포 키 노출)·무료한도. Leaflet=키 불필요. Leaflet도 GeoJSON 폴리곤·polyline 됨 |
| 영토 표현 | 슬라이더 morph 애니 | **연도 토글(레이어 swap)부터** | morph는 후순위 사치. 토글로 시작해 효과 검증 후 고도화 |
| 해설 생성 | Claude API 실시간 호출 | **❌ 거름 → 빌드시점 사전생성** | 정적 공개페이지 API 키 노출=보안/과금 사고. 해설은 episode.json에 미리 넣음(원칙: 데이터↔엔진 분리) |
| 옛 국경 | (불명확) | **PD 역사지도 image 블록** | 시대별 정확 폴리곤 데이터는 유료/없음. 중1엔 PD 고지도 이미지가 더 정직 |

## 3. 두 가지 지도 수단 (역할 분담 — 손그림은 영구 폐기)
1. **실제 지도 (Leaflet+OSM) — map 블록 ✅ 보유**
   - "어디서 일어났나" = 현대 지도 + 마커/팝업 + 경로선.
   - Type B/C/D 대부분. 키 불필요, 모바일 OK.
   - 한계: 현대 국경만 보임.
2. **공개도메인 역사지도 이미지 — image 블록 🔧 신설 예정**
   - "그때 국경/세력이 어땠나" = 옛 지도 정확히.
   - Type A(제국 분포 1900, 아프리카 분할 1914, 유럽 동맹 1914).
   - 출처: Wikimedia(PD-old) → 레포에 다운로드 호스팅, 출처·라이선스 표기.

## 4. 데이터 소스 (외부 문서에서 채택)
| 소스 | 용도 | 비용 | 우리 활용 |
|---|---|---|---|
| Wikimedia Commons (PD-old) | 역사지도 이미지 | 무료 | **1순위** (image 블록) |
| [Natural Earth](https://www.naturalearthdata.com/) | 현대 국경 GeoJSON | 무료 | Type A 영토 채색 시 베이스(현대 국경 한계 인지) |
| [David Rumsey](https://www.davidrumsey.com/) | 고지도 타일(WMTS) | 무료 | 분위기 배경 타일(후순위) |
| Geacron | 연도별 영토 API | 유료 | ❌ 도입 안 함 |

## 5. 우선순위 결론 (외부 문서 검토 후에도 불변)
1. **🔧 image 블록 신설** → PD 역사지도("옛 국경" 정직한 해법, 손그림 불만의 진짜 해소). **다음 라운드 1순위.**
2. **map(Leaflet) 챕터 확대** → 유럽 전선·태평양·인도·아편전쟁·조선(엔진 보유, 데이터만).
3. **🔧 compare 블록** → 전선/분단 전후.
4. (미래·Type A 에피소드) Leaflet + Natural Earth GeoJSON 영역 채색 + 연도 토글. **Mapbox·API 도입 안 함.**
