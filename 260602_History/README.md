# 세계대전 이야기 — HistoryTelling

중1 딸의 학교 **2차세계대전 탐구학습**을 돕기 위한 사이드바형 인터랙티브 학습 앱 프로젝트.
역사에 관심이 없던 딸이 **안네의 일기**라는 감성적 입구로 들어와, 제국주의에서 한국전쟁까지를 **하나의 이야기**로 경험하게 한다.

## 무엇을 만드나
- 좌측 사이드바 + 8개 섹션의 단일 웹 앱 (바닐라 HTML/CSS/JS)
- 섹션마다: 이야기 → 의미 → 핵심 카드 → 엄선 유튜브 → 내 생각 적기
- (선택) 딸과 함께 만드는 짧은 역사 영상

## 어떻게 일하나
- `00_project_hub/session/`에서 **파일 기반 라운드 대화**로 진행 (채팅 최소화)
- 콘텐츠 원천은 `30_content/*.md`, 사실 검증은 `20_research/`
- 자세한 규칙은 `CLAUDE.md`, 디자인은 `APP_PRINCIPLES.md`
