# Session — 콘텐츠/품질 개선 아이디어 보드 (0604~)

> 앞으로 라운드로 계속 누적하는 **아이디어 보드**. 각 아이디어 = 카드(무엇/효과/스키마·엔진 영향/난이도/상태).
> 고른 카드는 ▶ "프로토타입 라운드"로 엔진 블록 1개 구현 → ww2·imperialism 시범 적용 → 딸 반응 → distill.

## 핵심 원칙 (먼저 합의하고 싶은 것)
**모든 개선은 "엔진의 재사용 컴포넌트(=새 스키마 블록 타입)"로 추가한다.**
일회성 하드코딩 금지. 한 번 만들면 `episode.json`에 선택적으로 넣어 **전 에피소드가 혜택**. (지금 구조: 데이터↔엔진 분리 → 이게 유지보수·확장의 핵심.)
난이도 표기: S(작음)·M(중간)·L(큼).

---

## A. 비주얼라이즈 (Visualize)
- **A1. 인터랙티브 지도** — 시대별 세력/식민지를 색칠한 지도 위 핫스팟 클릭→설명. 효과: 공간 감각·흥미↑. [엔진: `map` 블록 + 인라인 SVG/좌표] [M~L] (1차는 정적 SVG+핫스팟 M)
- **A2. 가로 타임라인** — 현재 세로 타임라인을 줌/클릭 확장형으로, 나아가 에피소드 통합 연표. [엔진 확장] [M]
- **A3. 시대 분위기 이미지** — 히어로에 일러스트/AI 이미지(현재 SVG 모티프만). [스키마 `section.image` + `90_video` AI 이미지 파이프 차용] [M] (저작권/생성비 주의)
- **A4. 미니 데이터 시각화** — 간단 막대/그래프(식민지 면적, 군비 경쟁 등) 인라인 SVG. [엔진 `chart` 블록] [M]
- **A5. 인물 초상** — 퍼블릭도메인 사진/그림을 인물 카드에. [스키마 `person.img`] [S~M]

## B. 인터랙티브 (Interactive)
- **B1. 핫스팟 이미지** — 그림 위 점 클릭→설명(예: 안네 은신처 구조, 참호 단면). [엔진 `hotspot`] [M] 감정이입·탐구↑
- **B2. before/after 슬라이더** — 분단 전/후, 전쟁 전/후 도시·지도 비교. [엔진 `compare`] [M]
- **B3. "너라면?" 선택지** — 작은 의사결정(예: 조선의 외교 선택)→결과·해설. [엔진 `choice`] [M] 몰입↑(딸 성향에 강함)
- **B4. 플립 카드** — 인물/용어 앞뒤 뒤집기. [엔진 people/term flip] [S]
- **B5. 진행·성취 배지** — 섹션 완료/에피소드 완주 표시(현재 방문✓ 확장). [S]

## C. 퀴즈/평가 (Quiz)
- **C1. 섹션 끝 미니 체크** — 1~2문 객관식, 정답 강요X·즉시 해설. [엔진 `quiz` 블록 + 스키마] [M] ★quick win
- **C2. 에피소드 완주 퀴즈** — 5문 가볍게, 복습. [M]
- **C3. study-quiz 앱 연동** — 역사 퀴즈 JSON 생성→배포(기존 `/quiz-publish` 스킬 활용, 별도 레포). [M]
- **C4. 자기 채점 회고** — reflect와 결합한 가벼운 자기점검. [S]

## D. 학습 산출물 (탐구학습 직결 — 학교 과제로)
- **D1. 내 메모 모아보기 + 내보내기** — 섹션별 "내 생각" 메모를 한 곳에 모아 인쇄/복사 → 발표·보고서 초안. [엔진 notes export] [M] ★실용가치 큼
- **D2. 탐구 워크시트** — 에피소드별 질문지 인쇄용. [M]
- **D3. 인물 갤러리** `/history/people/` — 에피소드 가로지르는 인물 색인(안네·유관순·락슈미바이·임칙서…). [허브/엔진] [M]

## E. 품질 개선 방법론 (Quality methods)
- **E1. 멀티 페르소나 audit 정례화** — 역사학자·교사·균형심판·편집자·접근성. 병렬 에이전트 **동시 발사+개수 검증**(Ep02 교훈). [hist-audit 강화]
- **E2. 딸 피드백 루프** — 함께 보며 반응 기록→`learner-profile`→`hist-distill`로 원칙 반영. ★가장 중요한 품질 신호(우선순위를 계속 재조정)
- **E3. frontend-design 플러그인 패스** — 비주얼·접근성 다듬기(빌드 표준).
- **E4. 변형 비교(A/B)** — 같은 섹션 두 톤/구성 → 딸 선호 확인 후 채택.
- **E5. 접근성·모바일 우선** — 대비·터치타깃·글자 크기(폰 확인 중심).
- **E6. 영상 핀 정례화** — 검색링크(🔍)→특정 영상 교체 + 출처 `20_research`.
- **E7. 영상 제작(90_video)** — 스키마에서 대본 뼈대 추출→딸 참여 1분 영상.

## NCC 추천 — 시작 순서 (효과·실용 대비 노력)
1. **C1 섹션 미니 퀴즈** + **D1 메모 내보내기** (둘 다 엔진 블록, 모든 에피소드 즉시 혜택, 탐구학습 직결)
2. **A1 지도(정적+핫스팟)** + **B2 before/after** (역사 흥미·이해 큰 향상)
3. **D3 인물 갤러리** / **A3 시대 이미지** / **B3 선택지 분기**
4. 그리고 **E2 딸 피드백 루프**는 처음부터 상시 — 이게 다음 우선순위를 정해줌.
