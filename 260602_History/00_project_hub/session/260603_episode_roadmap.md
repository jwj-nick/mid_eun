# Session — 에피소드 로드맵 & 확장 방향 (2026-06-03)

> `/history/` 허브가 생겼으니, 다음 에피소드와 장기 확장 방향을 정리한다. Nick이 `(Nick)`으로 답하면 다음 라운드.

## Round 0 — NCC 추천

### 추천 기준 (딸 맞춤)
1. **정서·인물 중심** — 딸은 이야기·감정이입에 강함(국어/영어 강점). 안네처럼 *한 사람*으로 시대를 여는 구조가 잘 맞음.
2. **학교 탐구학습·교과 연결** — 산출물(메모·발표)로 바로 이어지는 주제.
3. **자연스러운 다리** — 방금 본 세계대전 이야기와 연결되면 몰입이 이어짐.
4. **허브 확장성** — 한국사/세계사/주제사 트랙으로 자랄 수 있는 구조.

---

### 다음 에피소드 (Ep 02) — Top 추천

**① 독립운동 이야기 — 빼앗긴 나라를 되찾기까지 ⭐ (가장 강추)**
- 입구 인물: **유관순**(또래 소녀) → "안네의 한국판" 정서적 입구. 안중근·윤봉길·임시정부로 확장.
- 다리: WWII 에피소드의 `50 일본·동아시아(식민지 조선/광복)` 섹션과 **직결**. "광복은 거저 온 게 아니었다."
- 탐구학습: 3·1운동, 독립운동가 인물 탐구 — 학교 과제로 바로 활용.
- 왜 강추: 정서+한국사 핵심+세계대전과의 연결, 세 박자가 다 맞음.

**② 인물로 보는 용기 — 세상을 바꾼 사람들 (주제사)**
- 안네·유관순의 정서를 넓혀 *용기 낸 사람들* 모음: 넬슨 만델라(용서), 마틴 루터 킹/로자 파크스(차별), 말랄라(소녀와 교육), 마리 퀴리(여성 과학자).
- 딸의 가치·글쓰기와 연결, 영어 원문 한 줄 맛보기(영어 강점 활용).
- 탐구학습: "내가 존경하는 역사 인물" 류 과제에 강함.

**③ 고대 문명 이야기 — 이집트·그리스·로마 (세계사 입문)**
- 신화·인물·유물로 흥미 유발. 중학 세계사 출발점.
- 다만 정서 몰입은 ①②보다 약함 → 흥미는 비주얼/이야기로 보완.

→ **NCC 1순위: ① 독립운동 이야기.** (연결성+정서+학교 활용 최고)

### 중기 로드맵 — 3개 트랙으로 확장

| 트랙 | 에피소드 예시 | 성격 |
|---|---|---|
| **한국사** | 독립운동(Ep02 후보) → 일제강점기 생활사 → 현대사(분단~민주화) → (거슬러) 조선·고려·삼국 | 학교 핵심, '우리 이야기' |
| **세계사** | 세계대전(Ep01✅) → 고대 문명 → 프랑스 혁명(자유·평등) → 냉전 이후 현대 세계 | 통사 흐름, 흥미 |
| **주제사** | 용기 낸 사람들 → 여성의 역사 → 인권의 역사 → 기록과 책의 역사(국어 연결) | 가치·글쓰기, 탐구학습 친화 |

> 사이드바를 트랙별로 묶거나, 허브에서 트랙을 고르게 하는 방향으로 자랄 수 있음.

### 포맷·기능 확장 방향 (에피소드 공통)
1. **영상 제작(90_video)** — "안네의 다락방에서 보낸 하루" 1분 영상부터, 딸이 내레이션/문구 참여. (math-story-telling 프로세스 차용)
2. **탐구학습 산출물 내보내기** — "내 생각 적기" 메모를 모아 **발표/보고서 초안**으로 내보내기(인쇄·복사). 학교 과제 직결.
3. **인물 카드 갤러리** — 안네·유관순… 인물 중심 색인 페이지.
4. **인터랙티브 지도·타임라인** — 전선/이동 경로를 눌러보는 지도, 가로 타임라인.
5. **미니 퀴즈/체크** — 섹션 끝 "기억나니?" 가벼운 확인 (정답 강요 X, 흥미 유지).
6. **유튜브 핀 고도화** — 현재 검색 진입(🔍) 3개를 특정 영상으로 교체 + `20_research/` 출처화.
