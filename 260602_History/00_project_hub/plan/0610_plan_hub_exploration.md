# 0610 — 신규 에피소드(시대 허브) 계획: 「바다 너머로 — 대항해시대」 (slug 후보: exploration)

> Nick 요청 #2. **제국주의 이전의 한 시대 = 대항해시대(15~17C)** 허브 + 하위 페이지.
> 이 시대가 '유럽이 세계로 뻗어나간 뿌리'이자, **#3 아메리카 허브로 이어지는 다리**. 서사 사슬: 대항해시대 → (아메리카) → 산업혁명·열강 → 제국주의 → 세계대전.

## 0. 정체성 / 구조
- **형식**: 새 **에피소드** `/history/exploration/` (엔진·블록 전부 재사용, 데이터만).
- **컨셉**: "왜·어떻게 유럽이 바다로 나가 세계를 잇고, 또 짓밟았나." 영광(탐험)과 그림자(정복·노예)를 **함께**.
- **시대 범위**: 1415(세우타) ~ 1600s 초. 인물·사건 중심 스토리.
- **대상 수준**: 계층적 깊이. ★균형 핵심: '발견'은 **이미 살던 사람들** 입장에선 '침략'. 아스텍·잉카·아프리카인 **voice/deepdive로 반드시 양쪽 시선**.
- **허브 갱신**: `/history/` 허브에 Episode 카드(시대순 맨 앞). 산업혁명(imperialism#industry)·아메리카 허브로 교차링크.

## 2. 🧑 인물 추가 (도감 확장)
- **엔히크 항해왕자**(포르투갈 탐험의 설계자)·**바스쿠 다 가마**(인도항로)·**콜럼버스**(논쟁적 — 빛과 그림자 분명)·**마젤란**·**코르테스**·**피사로**.
- 균형 인물: **목테수마**(아스텍 황제)·**아타우알파**(잉카 황제) — 정복당한 쪽의 얼굴.
- (선택) 이사벨 여왕(후원자). → 도감 +6~8인.

## 3. ★균형·수위 원칙 (이 에피소드 특히)
- '대항해=위대한 모험'으로만 그리지 않기. **정복·노예·전염병**의 비극을 또래 눈높이로, 존엄 있게(잔혹 직접묘사 절제).
- 원주민·아프리카인을 '배경'이 아니라 **주체**로(voice·deepdive·인물).
- 자산: 정복·노예 도해는 PD 역사자료, 출처표기. hist-audit 균형심판 필수.

## 4. 제작 순서 / 연결
- `hist-episode-plan` scaffold + 허브 카드 + build 등록. 섹션 0→7 순차(풀 업그레이드 표준 + G0~G3 + audit).
- **연결**: why-sea↔(오스만/향신료), conquest/slave-trade → **#3 아메리카 허브의 출발점**, commerce → imperialism#industry(자본·동인도회사).
