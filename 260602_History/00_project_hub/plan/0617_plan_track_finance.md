# 0617 — 분야 트랙 2호 계획: 「경제·금융 — 돈은 어떻게 세상을 움직이나」 (`tracks/finance`) ★

> 마스터플랜 `0614_masterplan_renaissance_to_ai.md` 분야축 5트랙 중 **금융·경제사**. sci-tech(1호) 완성 후 2호.

## 0. 한 줄 비전
**"종잇조각이 왜 가치를 가질까? — 돈·은행·주식·빚이라는 '보이지 않는 발명품'의 역사."**
경제·금융은 자연이 준 게 아니라 인류가 만든 약속과 장치다. 그 발명의 역사를 따라가며, 오늘 우리가 당연히 쓰는 돈·카드·물가·투자가 어떻게 생겨났는지 본다. **호기심 엔진과 최고 궁합** — 거의 모든 칸이 "그 전엔 없던 세상".

## 1. 위치·구조 (sci-tech 패턴 그대로)
- **`tracks/finance`** 단일 SPA (정거장=섹션). `/history/tracks/finance/`. 부모 랜딩 `tracks/`의 **'금융·경제' 카드를 활성화**(현재 '준비 중' → 라이브).
- 엔진/블록/배포 **전부 재사용**: `spark`(🤯)·`links`(외부 심화)·`chart`(지표·물가·주가 — 금융 트랙 주력)·`compare`(before/after)·`image`(≥2)·`choice`·`quiz`. **신규 엔진 0.**

## 2. 대상·톤 (sci-tech와 동일 + 생활 밀착)
- **대상 = 고등학생·일반인**(분야 트랙 표준, 이중 모델). 단 금융은 **10대 생활과 직결**(용돈·저축·카드·물가·알바비) → hook을 독자 일상에 강하게 건다.
- **호기심 엔진**(sci-tech에서 확립): wonder-first hook + 🤯 `spark`('그 전엔 없던 세상' + 상식뒤집기 mind-bender) + 📚 교과 연결(통합사회·경제·역사) + 🔗 외부 심화 링크(200검증) + 대표이미지 ≥2.
- **균형·중립**: 투자 권유·특정 상품/코인 추천 절대 금지(교육·역사만). 호황/거품·위기는 '구조와 인간 심리'로, 한쪽 이념 단정 회피(시장 vs 규제 양면). 암호화폐는 기술·논쟁 양면(투기 경고 포함).

### 3.1 S7 심화 — 「제국의 화폐 타락(debasement)」 (Nick 추가, 0617) ★
역사상 패권국들이 **재정·전쟁 비용을 메우려 돈의 가치를 스스로 떨어뜨린** 사례를 한 줄기로 묶는다. *"세계를 지배한 제국이 왜 스스로 돈을 망쳤을까?"* = 강력한 호기심 + '돈과 권력'의 교훈 + 시간축 허브 직결.
- **로마 — 데나리우스 타락:** 은화의 은 함량을 1세기 ~98% → 3세기 5% 아래로(같은 은으로 더 많은 동전을 찍으려). 3세기 위기·살인적 물가, 디오클레티아누스 가격 칙령(301)마저 실패. → **chart: 데나리우스 은 함량 추이**(충격 시각).
- **중국(송·명) — 세계 첫 지폐의 함정:** 송 교자(交子)~명 보초(寶鈔). 마구 찍어 가치 붕괴 → 지폐 폐기·은으로 회귀.
- **스페인 — 가격혁명:** 포토시(아메리카) 은 폭주로 16세기 유럽 물가 2~3배. 정작 은에 취한 스페인 제국은 쇠퇴(→ exploration#conquest·colonial 교차).
- **바이마르 독일 1923 — 하이퍼인플레:** 빵 한 덩이가 수십억 마르크, 지폐를 땔감으로. 사회 붕괴 → 나치 부상 배경(→ ww2 교차).
- **메시지·연결:** '돈을 더 찍으면 부유해진다'는 착각 → 가치만 묽어진다. 그래서 현대 중앙은행이 인플레이션을 관리한다(S3 은행·S5 달러·S8 2008과 연결). reflect="정부가 돈을 무한정 찍으면 모두 부자가 될까? 왜 아닐까?" mind-bender="로마는 칼이 아니라 자기 돈을 망쳐 무너지기 시작했다."
> **트랙 관통 테마로 승격:** '돈과 권력 — 화폐를 지배하는 자가 패권을 쥐고, 화폐를 망치면 잃는다'를 S5(달러 기축통화)·S2(거품)·S8(2008)에도 가는 실로 연결.

## 4. 정거장 구조 (호기심 엔진, sci-tech 동일)
`hook(일상 도발)` → 🤯 `spark`('그 전엔 없던 세상'+mind) → `why(개념·원리 + 숨은 경제)` → `cards(사건·인물·메커니즘)` → `chart`(지표: 물가·주가·통화량 등, 출처/대략값) → `image×2` → `compare/choice` → `connect` → `links` → `quiz` → `reflect(만약 없었다면 / 너라면)`.
- **chart가 금융 트랙 주력**(sci-tech의 compare 자리). 예: 대공황 실업률·하이퍼인플레 지폐액·2008 집값.
- **choice**(돈·윤리): "공황 때 너라면 은행에 돈을 남길까 뺄까?"·"빚을 내서 투자?" 균형 해설.
