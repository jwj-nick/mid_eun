# 0610 — 신규 에피소드 계획: 「유럽 열강 열전 — 제국을 세운 나라들」 (slug 후보: powers)

> Nick 요청 #1. 제국주의 시대 **유럽 열강을 나라별로** 깊이 보는 페이지 + **인물 추가**.
> 기존 `imperialism` 에피소드(산업혁명→화약고, 8섹션 완성)는 '시대의 흐름'을 다룸 → 이건 그 **자매편(나라별 열전)**. 흐름 본편을 건드리지 않고 별도 에피소드로 두어 서사 보존.

## 0. 정체성 / 구조 결정
- **형식**: 새 **에피소드** `/history/powers/` (imperialism과 같은 엔진·블록 전부 재사용, 데이터만).
  - (대안) imperialism에 섹션 추가 → 본편 8섹션 흐름이 흐트러져 **비채택**. 별도 에피소드 권장.
- **컨셉**: "같은 제국주의 시대, 나라마다 색이 달랐다." 한 나라 = 한 섹션. 각 나라의 **방식·대표 식민지·핵심 인물·빛과 그림자**.
- **대상 수준**: 계층적 깊이(중1 입구 + deepdive 고등/일반). 균형: 침탈자 시점만이 아니라 **당한 쪽**도 voice/deepdive로.
- **허브 갱신**: `/history/` 허브에 Episode 카드 추가. imperialism 본편에서 "나라별로 더 보기 →" 교차링크.

## 2. 🧑 인물 추가 (people.json → build_people, 도감 확장)
신규 인물(전부 PD 초상 목표):
- **비스마르크** (독일 통일·현실정치) ★
- **세실 로즈** (영국 제국주의의 화신, 케이프-카이로) ★ — why-empire image와 연결
- **레오폴드 2세** (벨기에, 콩고의 그림자) ★
- **빅토리아 여왕** (대영제국의 상징)
- (선택) **쥘 페리**(프랑스 식민 확장)·**디즈레일리**(수에즈)
> 각 인물: 다국어 이름·생애·연표·**빛과 그림자**(특히 로즈/레오폴드는 그림자 분명히)·관련 섹션 역링크. 도감 21→25~27인.

## 3. 자산 / 지도
- 지도: 나라별 **oldmap**(식민지 분포 PD 역사지도) 또는 **battlemap/territory**(팽창 단계). globe 승격 후보(영·러 전 지구) — 보류, oldmap 우선.
- 이미지: PD/CC0/CC BY-SA, 출처표기 (Commons API 격리 소싱). 풍자화·인물 초상·식민지도.
- 균형: 침탈 red / 저항 green. 콩고·헤레로 등 **가해의 구조**와 **피해의 존엄** 명시, 잔혹 직접묘사 절제.

## 4. 제작 순서 / 게이트
- 도입(overview)→영국→프랑스→독일→벨기에 순. 각 섹션 = 위 풀 업그레이드 표준(battlemap/oldmap·image·voice·deepdive5·order) + G0~G3 + hist-audit.
- 인물은 섹션과 함께 people.json 갱신 → build_people 재빌드.
- 새 에피소드라 `hist-episode-plan`/scaffold + 허브 카드 + build.py 대상 등록 필요(엔진/빌더는 그대로).
