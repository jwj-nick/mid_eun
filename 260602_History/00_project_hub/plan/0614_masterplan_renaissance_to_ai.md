# 마스터 계획서 — 르네상스에서 AI 시대까지 (시간축 연장 + 분야축 신설) ★

> Nick 지시(0614): 냉전·탈냉전·미중 패권·변화하는 질서까지 **시간축을 현재 AI 시대로 연장**(여러 앱으로 분할),
> 그리고 **과학기술/예술/문화/체육/금융 발달에 특화한 분야별 세계사 페이지를 별도 신설**.
> 르네상스 출발점부터 AI 시대까지를 하나의 마스터 플랜으로.
>
> 이 문서는 **확장 설계도**다. 구조 SSOT는 여전히 `10_docs/SERIES_ROADMAP.md` — 확정분은 그 표에 1줄씩 옮긴다.

## 0. 한 줄 비전
**"르네상스에서 AI까지, 가로(시간)와 세로(분야) 두 방향으로 읽는 세계사."**
정치·전쟁 중심의 시간 사슬(기존 9 허브)에, 인류가 무엇을 **만들고·그리고·즐기고·거래했는지**의 분야사 5트랙을 직교로 얹는다.

## 1. 2차원 모델 (THE MATRIX)
```
                     [시간축 = 정치·전쟁·사회 서사 사슬]
   르네상스 → 대항해 → 시민혁명 → 열강/제국 → 세계대전 → ❶냉전 → ❷탈냉전·세계화 → ❸다극·미중·AI
 ┌──────────────────────────────────────────────────────────────────────────────────────┐
A│ 과학기술사  과학혁명 → 항해술 → (산업혁명) → 전기·통신 → 원자·우주 → 컴퓨터 → 인터넷 → AI/반도체 │
B│ 예술사      르네상스미술 → 바로크 → 낭만 → 사진·인상 → 모더니즘 → 영화 → TV → 디지털·게임      │
C│ 문화·생활사  인쇄·종교개혁 → 시민 일상 → 대중사회 → 라디오 → 청년문화 → 인터넷 → SNS·K-컬처      │
D│ 체육·스포츠사 (근대 이전) → 근대올림픽 부활 → 프로화 → 냉전 스포츠대결 → 글로벌 메가이벤트       │
E│ 금융·경제사  상업혁명 → 주식회사·중앙은행 → 대공황 → 브레튼우즈 → 신자유주의 → 글로벌금융·코인   │
 └──────────────────────────────────────────────────────────────────────────────────────┘
   [분야축 = 시간을 가로지르는 5 트랙 — 각 트랙이 별도 SPA, 시대별 '정거장'으로 시간축과 교차링크]
```
- **세로 트랙 × 가로 사슬이 만나는 칸** = cross-link 지점. 예) 예술사의 '르네상스미술' 정거장 ↔ `renaissance` 허브, 금융사의 '브레튼우즈' ↔ `coldwar` 허브.
- 분야 트랙은 시간순 사슬이 아니라 **주제 통사** → 아메리카(지역 허브) 패턴을 그대로 빌린다(`tracks/` 네임스페이스 = 부모 랜딩 + 자식 트랙).
- 엔진/블록은 **전부 재사용**(battlemap·oldmap·deepdive·voice·chart·compare·choice·image·map·relations·movieBlock). 데이터만 채운다.

## 2. 시간축 연장 — 새 허브 3개 (❶❷❸)

### ❶ 냉전 `coldwar` (1945–1991) — 최우선·최저비용
- **범위:** 양극체제·핵 균형(공포의 균형)·철의 장막·베를린/쿠바·대리전(6·25는 ww2가 다룸→여기선 베트남·아프간)·우주경쟁·데탕트·장벽 붕괴.
- **인물 재사용(신규 소싱 ≈ 0):** 스탈린·마오·김일성·트루먼·맥아더·이승만·오펜하이머 **전원 이미 도감 floor**. 신규는 케네디·흐루쇼프·고르바초프 정도(3~4인 추가).
- **섹션 스케치(8):** ① 두 진영의 탄생(yalta→철의장막) ② 핵·공포의 균형(chart: 핵탄두 수) ③ 베를린·장벽(oldmap+battlemap) ④ 쿠바 미사일 13일(choice: 핵전쟁 직전 선택) ⑤ 대리전과 제3세계(베트남) ⑥ 우주경쟁(스푸트니크→달, sci-tech 트랙과 교차) ⑦ 데탕트와 균열 ⑧ 장벽이 무너지다(1989→toward-globalization).
- **연결:** ww2#postwar → coldwar / coldwar#fall → globalization.
- **균형심판 주의:** 어느 진영도 미화/악마화 금지. '그때 양쪽이 본 세계'. 김일성은 도감 원칙 유지(우상화 배제).

### ❷ 탈냉전·세계화 `globalization` (1991–2008)
- **범위:** 소련 붕괴·단극(미국)·세계화·WTO·EU·인터넷 보급·9/11과 테러전쟁·중국의 부상 시작.
- **인물:** 신규 다수(고르바초프 겹침, 만델라, 덩샤오핑은 coldwar/여기 경계). 현대 인물 = **저작권 주의**(생존/근현대 → PD 사진 거의 없음 → 장소·상징·자료 이미지 + 링크 정책).
- **섹션 스케치(7):** ① 소련이 사라지다 ② 하나의 시장(세계화·컨테이너·WTO) ③ 인터넷이 연결하다(sci-tech 교차) ④ 9·11과 흔들린 단극 ⑤ EU·통합의 실험 ⑥ 잠에서 깬 중국(덩샤오핑 개혁개방→toward-neworder) ⑦ 평평해진 세계의 명암.
- **균형심판:** '역사의 종말' 낙관과 그 반론 양쪽 제시. 9·11은 중1 수위로 신중히(추모·결과 중심, 잔혹묘사 회피).

### ❸ 다극·미중 패권·AI 시대 `new-order` (2008–현재)
- **범위:** 글로벌 금융위기(2008)→다극화·미중 경쟁·기술/반도체 전쟁·기후·팬데믹·**AI 시대의 개막**. 사슬의 현재 끝칸.
- **AI 강조:** Nick의 NPU/AI 커리어와 직결 — 마지막 섹션을 **'AI가 바꾸는 질서'**(반도체=새 석유, 알고리즘과 데이터)로 클라이맥스. 향후 자체 허브 `ai-era`로 승격 여지(KEEP).
- **섹션 스케치(7):** ① 2008, 금이 간 신뢰(finance 교차) ② 다극의 세계(미·중·EU·인도) ③ 미중 패권경쟁(무역·기술·대만) ④ 반도체 전쟁(sci-tech 교차, Nick 전문) ⑤ 연결된 위기(기후·팬데믹) ⑥ AI가 온다(컴퓨팅→딥러닝→생성형) ⑦ 우리가 만들 질서(choice: 정답 없는 미래, 열린 결말).
- **⚠️ 균형·수위 핵심:** **현재진행 정치** = 가장 민감. 당파·국가 편향 금지, '진행 중이라 답이 없음'을 명시(choice/after로). 중1에게 과한 불안 주지 않기. 출처는 사실·합의된 것만, 추정은 '추정'으로.

> **분할 근거:** 한 SPA 8섹션 한계 + 시기·성격 상이(양극/단극/다극) → 3 앱이 적정. AI는 ❸의 정점으로 시작, 콘텐츠가 커지면 분리.

## 3. 분야축 신설 — 트랙 5종 (`tracks/` 지역허브 패턴)

> 각 트랙 = 별도 SPA. 시대별 **정거장(station)** 으로 구성(르네상스→AI). 각 정거장은 해당 시간 허브로 cross-link.
> 부모 랜딩 `tracks/`(분야 5칸 그리드) + 자식 5 SPA. = americas 패턴 재사용.

| slug | 분야 | 정거장(르네상스→AI) | 주력 블록 | Nick 교집합 |
|---|---|---|---|---|
| `tracks/sci-tech` | 과학기술사 | 과학혁명→(산업혁명)→전기·통신→상대성·원자→컴퓨터→인터넷→**AI·반도체** | compare(기술 사다리)·chart·deepdive | ★최강(codec/NPU) |
| `tracks/art` | 예술사 | 르네상스미술→바로크→낭만·사진→인상·모더니즘→영화→디지털·게임 | image(작품)·compare·movieBlock | 영상/영화 |
| `tracks/culture` | 문화·생활사 | 인쇄·종교개혁→시민일상→대중사회→라디오·TV→청년문화→SNS·K컬처 | voice·image·deepdive | — |
| `tracks/sports` | 스포츠사 | 근대올림픽 부활(1896)→프로화→**냉전 스포츠대결**→글로벌 메가이벤트 | chart·compare·choice | — |
| `tracks/finance` | 금융·경제사 | 상업혁명→주식회사·중앙은행→대공황→브레튼우즈→신자유주의→글로벌금융·코인 | chart(지표)·compare·deepdive | — |

- **정거장 = 가로 연표**: 신규 블록 후보 1개 → `timeline`(가로 스크롤 연표). 단 **초기엔 만들지 않는다** — `compare`(단계 전환)로 충분히 대체 가능. 트랙 3개쯤 만든 뒤 필요하면 승격(엔진 재사용 원칙 준수).
- **인물 재사용:** sci-tech는 갈릴레이·뉴턴·오펜하이머 등 도감에서 끌어옴. 트랙↔도감 양방향 링크(백로그의 '도감→figures 역링크'와 합류).
- **저작권:** 예술사 = 작품 이미지는 **작가 사후 70년+ PD 또는 미술관 오픈액세스(메트·NGA·라익스)** 만. 현대미술·영화 포스터·음악 = 링크 정책(이미지 금지).
