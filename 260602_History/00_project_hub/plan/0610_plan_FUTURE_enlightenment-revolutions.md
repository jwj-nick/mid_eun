# 0610 — [FUTURE / KEEP] 시대 아이디어: 「자유를 향하여 — 계몽과 시민혁명의 시대」 (slug 후보: revolutions)

> Nick 지시: 대항해시대(채택) 외 **보관해 둘 시대 아이디어 #1**. 나중에 실제 제작할 아이템. (지금은 착수 X, 설계만 저장)
> 시대: 17C 후반 ~ 19C 초 (계몽사상 → 시민혁명 → 나폴레옹). **제국주의의 '바로 직전' 시대** — 자유·국민국가·민족주의의 탄생이 곧 제국주의/세계대전의 동력으로.

## 0. 정체성
- 새 에피소드 `/history/revolutions/`. 엔진·블록 재사용.
- 컨셉: "왕의 시대에서 국민의 시대로 — 생각(계몽)이 어떻게 세상을 뒤엎었나." 사상→혁명→반동의 드라마.
- 산업혁명은 imperialism#industry에서 이미 다룸 → 여기선 **정치·사상 혁명**에 초점(중복 회피). 필요 시 '이중 혁명'(정치+산업) 1섹션으로 산업혁명과 교차.

## 2. 인물 (도감)
- 로크·몽테스키외·루소·볼테르(계몽), 로베스피에르, **나폴레옹**, (가리발디·비스마르크는 powers와 공유).

## 3. 연결 / 가치
- 강함: **민주주의·인권의 기원** = 오늘 우리 제도의 뿌리(현재성 강함, 탐구학습 유용).
- 그물: american-rev↔아메리카 허브 · nationalism↔제국주의/세계대전(민족주의) · enlightenment↔북미 독립.
- ★균형: 혁명의 이상 + 공포정치·식민지엔 적용 안 된 '자유'(노예·여성·식민지)의 모순도.
