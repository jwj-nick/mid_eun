# 0616 — sci-tech 콘텐츠 업그레이드 계획: 「호기심 엔진」 + 전용 과학 스킬 ★★

> **Nick 피드백(0616):** "오늘날 너무 당연하게 여기는 것들이, 개발·발명·산업화 전에는 존재하지 않았다 — 그게 상상이 가니? 이런 호기심을 자극하는 내용이 필요하다. 지금은 **과학적 호기심보다 그냥 역사 얘기 뉘앙스**라 평이하고 **엣지가 없다.** 과학 얘기는 **또 다른 전용 내용-제작 스킬·플로우**가 있어야 한다. **내용 업그레이드 계획부터** 세워라. **단원 수도 늘려도 된다.**"
> (코덱/NPU 본문 검수 = 수정 불필요 OK.)

## 0. 진단 — 왜 지금이 '평이'한가
- 현재 정거장은 **연대기(누가·언제·무엇)** 중심. 정확하지만 "그래서 놀랍다"는 감각이 약하다.
- hook이 종종 **인물·사건**으로 열린다(역사 톤). 과학 트랙의 hook은 **경이·도발(현재의 당연함을 낯설게)** 로 열어야 한다.
- '오늘 내 손안의 당연한 것 ↔ 그게 없던 세상'의 **충격적 대비**가 거의 없다 = 엣지 부재.
- 결론: **내용을 다시 쓰는 게 아니라, 모든 정거장에 '호기심 레이어'를 입히고 wonder-first로 재구성**한다. 사실·교과 연결·외부 링크는 유지.

---

## 1. 호기심 엔진 (★ 이 트랙의 새 심장) — 5가지 장치
모든 정거장이 **최소 3개**를 쓴다. 정확성 위에 '경이'를 얹는다.

1. **🤯 그 전엔 없었다 (낯설게 하기 / Before-this):** 지금 너무 당연한 것을, "불과 N년 전엔 존재하지 않았다"로 충격적으로 제시. *예: "150년 전엔 손톱 밑 상처로도 죽었다."*
2. **🔍 네 일상 속 숨은 과학 (Hidden science in the everyday):** 독자가 매일 쓰면서 한 번도 안 궁금했던 것의 정체. *예: "네 폰의 GPS는 아인슈타인의 상대성이론을 매 순간 보정한다."*
3. **🌀 상식을 뒤집는다 (Mind-bender):** 직관을 깨는 한 방. *예: "지금 너는 시속 10만 km로 태양을 돌고 있다 — 왜 안 느껴질까?"*
4. **❓ 만약 없었다면 (Counterfactual):** 그것을 빼앗긴 하루/세상을 상상. *예: "전기가 사라진 밤을 상상해보라."*
5. **📊 숫자의 충격 (Scale shock):** 규모를 체감시키는 비교. *예: "네 주머니 폰 > 1969년 NASA 컴퓨터 전부 × 수백만."*

### 정거장 작성 템플릿 (wonder-first 재구성)
`hook=경이/도발(장치①③)` → `spark=🤯 그 전엔 없던 세상(신규 블록)` → `why=그래서 무엇이 바뀌었나(+숨은 과학 장치②)` → `cards=핵심(메커니즘·인물)` → `image×2` → `lens/choice` → `connect` → `links` → `quiz(호기심형)` → `reflect(만약 없었다면 장치④)`.

## 2. 정거장별 '호기심 앵커' (9개 — 새 hook/spark의 씨앗, 엣지 시연)
| 정거장 | 호기심 앵커 (이 톤으로 다시 쓴다) |
|---|---|
| 과학혁명 | "지금 너는 **시속 약 10만 km로 태양을 돌고** 있다. 안 느껴지지? 400년 전 사람들은 '땅이 움직인다'는 말을 미친 소리로 여겼다." |
| 산업혁명 | "이 방의 거의 **모든 물건을 '기계'가 만들었다.** 250년 전엔 세상 모든 것이 사람 손에서 나왔고, 그래서 대부분 가난했다." |
| 화학·물질 | "네 **몸속 질소의 절반은 '공장'에서 왔다.** 비료를 만들지 못하던 100년 전, 인류는 늘 굶주림의 문턱에 있었다." |
| 전기·통신 | "150년 전 **밤은 진짜로 깜깜했고**, 소식은 말[馬] 속도로만 움직였다. 지금 너는 지구 반대편과 0.1초 만에 얼굴을 본다." |
| 의학·생명 | "**150년 전엔 손톱 밑 상처로도 죽었다.** 의사들은 손을 안 씻었고, '보이지 않는 생물이 병을 옮긴다'를 비웃었다." |
| 원자·우주 | "네 **폰의 GPS는 '시간이 느리게 간다'는 아인슈타인의 말을 매 순간 보정**한다. 안 하면 하루에 약 10km씩 틀린다." |
| 컴퓨터 | "지금 주머니 속 폰은 **인류를 달에 보낸 1969년 NASA의 컴퓨터 전부보다 수백만 배 빠르다.**" |
| 인터넷 | "**30년 전엔 '검색'이 없었다.** 모르면 도서관에 갔다. 그리고 네가 보는 영상은 압축 없이는 한 편에 DVD 수백 장이 필요하다." |
| AI·반도체 | "**누구도 기계에게 '고양이'를 정의해준 적이 없다.** 그런데 기계가 고양이를 알아본다. 어떻게?" |

> 이 한 줄들이 각 정거장의 새 hook·spark의 핵심이 된다. 나머지 본문은 이 경이를 '풀어주는' 방향으로 재배치.

## 3. 구조 변경 + 신규 `spark` 블록 (엔진)
- **wonder-first:** hook 직후 **`spark` 블록**(🤯 강조 콜아웃)으로 '그 전엔 없던 세상'을 시각적으로 때린다. 그다음 why가 과학으로 받는다.
- **신규 `spark` 블록 스펙:** `spark:{ icon?, title, body, mind? }` → 눈에 띄는 박스("🤯 상상해보기"). `mind`=상식 뒤집는 한 줄(장치③). 엔진에 `sparkHTML`+CSS 추가(`links` 블록 추가했던 방식, `node --check`). 정거장당 1개.
- 기존 블록(hook·why·cards·image·lens·choice·connect·links·quiz·reflect)은 유지하되 **톤을 '엣지'로** 다시 씀.

### 문체(엣지) 규칙
- **경이 먼저, 연대기 나중.** 날짜로 열지 않는다.
- 짧고 센 문장 + 직접 호명("지금 네 손안의…"). 감각적 대비(어둠·통증·굶주림·거리·속도).
- **정거장당 '와, 진짜?' 한 방**(mind-bender) 필수. 과장·왜곡은 금지(수치는 출처/대략값).
