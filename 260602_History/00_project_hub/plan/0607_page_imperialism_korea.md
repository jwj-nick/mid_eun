## 1. 🗺️ 지도 (MAP_TOOLKIT 적용)
1. **동학: marchmap → battlemap 승격(권장)** — 전라·충청 **확대** Leaflet + 흐르는 화살표 + 격전지 + 범례 + 수동 스테퍼. (Q1 위치·Q4 겹침 해소). marchmap은 대안 보존.
2. **청일전쟁 battlemap** — 풍도해전→평양→압록강→뤼순→웨이하이웨이(침탈 화살표) + 시모노세키.
3. **러일전쟁 battlemap** — 뤼순→펑톈→쓰시마 해전.
4. **고지도 인서트(oldmap)** — 1818/19세기 한국·동아시아 PD 고지도로 '시대감' 한 컷.
5. relations(조선 각축)와 지도를 **나란히** 배치(구도→지도 연계).

## 2. 🎨 비주얼
- **이미지**: 전봉준 압송(1895, 도감 보유)·경복궁(을미사변 현장) PD 사진 + 캡션.
- **차트**: 불평등조약/배상·개항장 추이 등 간단 막대(자체 chart 블록 보유).
- **compare**: 갑오개혁 전/후(신분제·제도) 토글.
- **voice**: 전봉준 공초(심문 기록) 기반 1차 사료 인용(실제 배지) 또는 동학 격문 한 줄.
- 타이포·인용 카드·여백 폴리시(frontend-design).

## 3. 📚 내용 — "더 깊이 ▾"(고등/일반) 심화 레이어
중1 본문은 유지, 아래 토글에 심화:
- **인과 체인**: 동학(1894)→청일전쟁→시모노세키(랴오둥·배상)→삼국간섭→을미사변(1895)→아관파천(1896)→대한제국(1897). "사건이 사건을 부르는" 구조.
- **갑오개혁** 핵심(신분제 폐지 등)과 한계(일본 영향).
- **사상**: 동학 '인내천'·'보국안민'의 의미.
- **관점·논쟁(historiography)**: 명성황후 평가 엇갈림 / '동학란 vs 동학농민혁명' 명칭 논쟁 / 갑오개혁 자주성 논쟁.
- **1차 사료**: 전봉준 공초, 폐정개혁 12개조(요지).
- **용어 정밀**: 종주국·불평등조약·조계·배상금 등 고등 수준 정의.

## Round 1 — 구성 재검토 (NCC 분석 + 제안)

### 현재 렌더 순서 (실측 — 엔진 `episode.html` 전역 고정)
hook → why → **voice(공초)** → cards(5) → people(2) → **map(옛 단일지도)** → image(압송) → chart(개항장) → compare(갑오개혁) → relations(청·일·러) → battlemap①동학 → battlemap②청일/러일 → timeline → connect → yt → choice → deepdive → reflect

### 문제점 (왜 "구성 다시"가 맞나)
- **A. 옛 `map` 블록 잔존(중복)** — 동학·청일/러일 battlemap 3개가 있는데, Nick이 싫어했던 **작은 점·겹침의 옛 단일 조선 지도**가 그 앞에 또 나온다. → **제거 1순위(저위험).**
- **B. voice(전봉준 공초)가 너무 이르다** — 동학 설명(cards)·동학 battlemap·압송 사진을 보기도 **전에** 1차사료 인용이 튀어나와 정서적 클라이맥스가 흩어진다. 공초는 "동학 battlemap→압송 image" **직후**에 와야 맞다.
- **C. 비주얼이 한 덩어리로 쏟아짐** — image·chart·compare·relations·battlemap×2가 연달아 폭탄처럼 나오고 **timeline이 그 뒤에 뒤늦게** 온다. "설명→비주얼 폭탄→연표"라 서사가 끊긴다.
- **D. 순서가 엔진 전역 고정** — 섹션마다 강조점이 다른데 순서를 못 바꾼다. ★ 이게 **"workflow도 업그레이드"의 핵심**.

### 제안 — 2층 구조
**(1) 즉시 정리 (이 페이지, 저위험):** 옛 `map` 블록 제거.

**(2) 워크플로우 업그레이드 (엔진):** 섹션별 블록 순서를 데이터로 제어.
