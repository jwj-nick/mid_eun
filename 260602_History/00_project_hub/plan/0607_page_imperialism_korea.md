# 0607 — 첫 대상 페이지 세부 개선 플랜: imperialism / "위기의 조선"

> 마스터플랜(`plan/0607_visual_content_masterplan.md`)의 첫 대상. 지도 방식은 `10_docs/MAP_TOOLKIT.md`.
> 목적: 이 한 섹션을 **지도·비주얼·내용** 3축으로 '끝까지' 끌어올려 **기준 사례**를 만든다. 패턴을 다른 섹션에 전파.
> 대상 수준 = **계층적 깊이**: 중1 감성 입구 유지 + **"더 깊이 ▾"(고등/일반)** 레이어 추가.

## 0. 현재 보유 (출발점)
- people: 명성황후·전봉준(slug, 도감 역링크) · relations: 조선 각축(청·일·러 3진영) · **marchmap: 동학 우금치(신규)** · hook/why/cards/lens/timeline/connect/yt/reflect.
- 한계: 동학 지도가 한반도 전체라 점이 작고 라벨 겹침(Nick 지적). 내용이 중1 단일 수준. 시대감(고지도) 미적용.

## 1. 🗺️ 지도 (MAP_TOOLKIT 적용)
1. **동학: marchmap → battlemap 승격(권장)** — 전라·충청 **확대** Leaflet + 흐르는 화살표 + 격전지 + 범례 + 수동 스테퍼. (Q1 위치·Q4 겹침 해소). marchmap은 대안 보존.
2. **청일전쟁 battlemap** — 풍도해전→평양→압록강→뤼순→웨이하이웨이(침탈 화살표) + 시모노세키.
3. **러일전쟁 battlemap** — 뤼순→펑톈→쓰시마 해전.
4. **고지도 인서트(oldmap)** — 1818/19세기 한국·동아시아 PD 고지도로 '시대감' 한 컷.
5. relations(조선 각축)와 지도를 **나란히** 배치(구도→지도 연계).

## 2. 🎨 비주얼
- **이미지**: 전봉준 압송(1895, 도감 보유)·경복궁(을미사변 현장) PD 사진 + 캡션.
- **차트**: 불평등조약/배상·개항장 추이 등 간단 막대(자체 chart 블록 보유).
- **compare**: 갑오개혁 전/후(신분제·제도) 토글.
- **voice**: 전봉준 공초(심문 기록) 기반 1차 사료 인용(실제 배지) 또는 동학 격문 한 줄.
- 타이포·인용 카드·여백 폴리시(frontend-design).

## 3. 📚 내용 — "더 깊이 ▾"(고등/일반) 심화 레이어
중1 본문은 유지, 아래 토글에 심화:
- **인과 체인**: 동학(1894)→청일전쟁→시모노세키(랴오둥·배상)→삼국간섭→을미사변(1895)→아관파천(1896)→대한제국(1897). "사건이 사건을 부르는" 구조.
- **갑오개혁** 핵심(신분제 폐지 등)과 한계(일본 영향).
- **사상**: 동학 '인내천'·'보국안민'의 의미.
- **관점·논쟁(historiography)**: 명성황후 평가 엇갈림 / '동학란 vs 동학농민혁명' 명칭 논쟁 / 갑오개혁 자주성 논쟁.
- **1차 사료**: 전봉준 공초, 폐정개혁 12개조(요지).
- **용어 정밀**: 종주국·불평등조약·조계·배상금 등 고등 수준 정의.

## 4. 신규 엔진 (재사용 — 전 페이지 공통 자산)
1. **`deepdive` 블록(★계층적 깊이의 핵심)** — "더 깊이 ▾" 접이식. 데이터: `deepdive:[{h, body, source?, terms?}]`. 닫힘 기본(중1 방해 X), 열면 고등/일반 심화. **이게 이번 작업의 가장 큰 재사용 산출물.**
2. **`battlemap` mode 승격** — maplab T0-A 로직을 엔진 블록으로(ant-path CDN). 동학·청일·러일에 사용.
3. (선택) `oldmap` 인서트 블록 — 고지도 이미지 + 캡션.

## 5. 작업 단계 (게이트 동반)
1. **deepdive 엔진 블록** 신설(+CSS+JS_OK G1) → 위기의 조선에 심화 5개 데이터.
2. **battlemap 엔진 블록** 신설 → 동학(확대) 교체 + 청일·러일 추가. 좌표 G2.
3. 비주얼: image·compare·voice·chart 데이터 채우기.
4. 빌드(G0/G1) → 배포(G3 라이브) → 시각·관점 리뷰(R1·R2) → 소스 카테고리 커밋.
5. EPISODE_SCHEMA(deepdive·battlemap)·PROGRESS·MAP_TOOLKIT 현황 갱신.

## 6. 완료 기준 / 전파
- 위기의 조선: 지도 3종 + 고지도 + 심화 토글 + 비주얼 강화가 라이브.
- **deepdive·battlemap이 재사용 엔진으로 확보** → 다른 섹션(아편전쟁·인도·안네 등)에 데이터만으로 적용.
- 이 페이지가 '기준 사례' = 이후 페이지 개선의 템플릿.

## 7. 열린 점
- 동학 지도: battlemap(정확·줌) vs marchmap(연출) — 둘 다 두고 토글 제공할지.
- 심화 레이어 분량(너무 길면 중1 압도) — 토글 닫힘 기본 + 항목 3~5개로 절제.
- 사료 인용 저작권/번역 — PD·요지 인용으로.
