# 종교 허브 `religion/` — "믿음의 역사" 마스터플랜 (0623)

## 한 줄
사람은 무엇을, 왜 믿어왔나. **종교 그 자체에 집중**한 별도 최상위 허브 — 세계 4편(불교·유대교·그리스도교·이슬람) + 한국 3편(한국 불교·천주교·개신교). 기존 허브(axial-age·islam·medieval-europe·한국사)에 흩어진 종교 서사를 **종교사·비교문화 렌즈**로 한데 모으고 교차링크.

## Nick 확정 (AskUserQuestion 0623)
- **구조 = 별도 최상위 종교 허브** (`/history/religion/`, korea·americas처럼 독립). tracks 하위 아님.
- **세계 = 4페이지**: 불교 / 유대교 / **그리스도교(천주교+개신교 한 페이지, 종교개혁으로 분기)** / 이슬람.
- **한국 = 종교별 여러 페이지**: 한국 불교 / 한국 천주교 / 한국 개신교 (각각 별도).

## ★ 절대 원칙 (종교 = 최고 민감도 — 반드시 준수)
1. **종교사·문화사 렌즈.** "믿는다 / 가르친다 / 전한다"로 서술. **진위·우열·참거짓 단정 금지.** 어느 종교도 옳다/그르다, 우월/열등으로 두지 않는다.
2. **경전·교리·기적·창조·계시 이야기 = '그 종교가 전하는 바'로 소개**하고 역사적 사실과 **명확히 구분**(legend 블록 + moral 패턴, "신화·전승은 사실과 구분" 원칙 그대로).
3. **★ 무함마드(및 예언자) 형상 묘사 절대 금지.** 이슬람 시각자료 = 쿠란 서예·기하 아라베스크·모스크 건축·캘리그래피만. 인물 도상 0.
4. **종교 간/내부 갈등(십자군·종교재판·박해·종파분쟁·신사참배 거부)** = 정직하되 한쪽 미화/악마화 없이, **잔혹 수위 절제.**
5. **한국 종교**: 불교 억불·천주교 박해·개신교 선교는 **당대 국가·정치·문화 충돌의 맥락**으로. 특정 신앙 옹호/비판 아님.
6. **현대 살아있는 신앙 공동체 존중** — 신자 비하·희화화 금지. 교세·통계는 사실 출처.
7. **이미지 = PD/CC/CC0/KOGL만 + 전점 Read 육안검수 + 라이선스 정확.** 종교미술·건축·사본·유물 중심.
8. **수준 = 고등 심화**(본문 고교 깊이: 교리 구조·역사 인과·분파·논쟁), **입구(훅)는 누구나**. 호기심 입구 유지.
9. 배포 전 **hist-audit 균형심판 필수**(종교는 균형 게이트가 핵심).

## 페이지 로스터 (1 랜딩 + 7 에피소드)
### 세계 (4)
- **`religion/buddhism` 🪷 불교** — 붓다의 물음(축의시대 연결)·사성제/팔정도·무아/연기·상좌부↔대승 분기·전파(스리랑카→동남아 / 중앙아→중국→한국·일본 / 티베트)·선(禪)·아소카의 후원. 인물: 붓다·아소카·나가르주나·보리달마.
- **`religion/judaism` ✡️ 유대교** — 아브라함의 계약·출애굽(전승)·토라/탈무드·성전과 디아스포라·랍비 유대교·중세 박해·근현대(반유대주의→홀로코스트→이스라엘, **균형·음모론 해체** 재확인). **그리스도교·이슬람의 공통 뿌리**임을 강조.
- **`religion/christianity` ✝️ 그리스도교** — 예수·초대교회·바울의 전도·로마 박해→콘스탄티누스 공인→국교·교부(아우구스티누스)·동서 분열(정교회)·중세 교회와 십자군·스콜라·**종교개혁(루터·칼뱅)→천주교/개신교 분기**·근현대. (천주교+개신교 묶음)
- **`religion/islam` ☪️ 이슬람** — 무함마드(**형상 0**)·쿠란·다섯 기둥·수니/시아 분기·정통 칼리프·우마이야/아바스·**황금기**(islam 문명 허브와 교차링크)·수피즘·확산. '종교 자체'에 집중.

### 한국 (3)
- **`religion/korea-buddhism` 🛕 한국 불교** — 삼국 전래(고구려 372·이차돈 순교)·원효(화쟁)·의상·통일신라 불국토·고려 국교(팔만대장경)·조선 억불·서산대사 승병·근현대.
- **`religion/korea-catholicism` ⛪ 한국 천주교** — **서학(西學)으로 책을 통해 전래**(자생적 수용)·이벽·이승훈·정약용 형제·신해/신유/기해/병인박해·김대건(첫 한국인 사제)·주문모·근현대.
- **`religion/korea-protestant` ✝️ 한국 개신교** — 19세기말 선교(언더우드·아펜젤러)·교육(배재·이화)·의료(제중원)·한글 성경·독립운동(3·1·신사참배 거부)·근현대 성장과 명암.

## 페이지 구성(블록) — 엔진 변경 0, 전부 기존 블록 재사용
- 표준 흐름: **hook(호기심 입구) → spark/why(왜 중요) → 핵심 교리/서사 cards·legend(경전 일화, moral로 사실구분) → compare(분파·교리 비교) → map(전파 경로 Leaflet) → image(종교미술·건축·사본 ≥2/섹션, 전점 검수) → deepdive(고교 심화) → people(핵심 인물 emoji-face) → quiz → reflect/links(교차링크)**.
- legend = 경전·창조·기적 이야기를 '전해지는 바'로(moral에 "이는 신앙의 이야기로, 역사적 사실과는 구분"). compare = 상좌부vs대승, 천주교vs개신교, 수니vs시아 등. lineage(선택) = 교황 계보·조사(祖師) 계보엔 무리 — 미사용.
- 이슬람: image/oldmap/map만(서예·모스크·아라베스크·쿠란 사본·확산 지도), 인물 블록은 emoji-face·이름만(무함마드 도상 0).
