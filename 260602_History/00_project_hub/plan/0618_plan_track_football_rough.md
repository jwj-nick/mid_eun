# ROUGH PLAN — 분야 트랙: 축구 (스포츠, ⚽ 전용) ★초안

> Nick 지시: "스포츠로 넘어가기. 완전히 축구에만 집중. rough plan 필요. 과거 역사부터 현재 빅리그 시스템, 빅리그 이외 각국 시스템 포함."
> 인프라 = 분야트랙 표준 재사용(공유 엔진 `episode.html`, 호기심 엔진 `tracks-write`, compare/chart 블록, deploy.py 파이프라인). **콘텐츠만 새로.**

## 1. 비전
공 하나로 세계가 연결된 게임. **축구가 어떻게 생겨나 세계 1위 스포츠가 됐고(역사) → 오늘날 어떤 '시스템'(리그·돈·이적·거버넌스)으로 돌아가며(빅리그) → 그 시스템이 나라마다 어떻게 다른가(세계)** 를 고등/일반 눈높이 + 호기심 엔진으로. 단순 '경기/스타' 나열이 아니라 **'축구라는 거대한 시스템'을 읽는 눈**.

## 2. 대상·톤 ★확정(0618)
- **수위 = 최고급 전문가 수준**(Nick 확정). 고등/일반 단순화가 아니라 축구 산업·시스템을 실제 메커니즘까지: 리그 피라미드·낙하산지원금, 중계권 집단판매 vs 개별판매, 50+1과 예외, 소유구조(국부펀드·멀티클럽), FFP→PSR/스쿼드 코스트 비율, 이적료 회계(상각)·에이전트 규제·보스만/웹스터, 슈퍼리그·ECJ 판결, 3자 소유 금지, J리그 100년 구상, MLS 단일주체·DP룰, xG/데이터 리크루팅.
- 호기심 훅(wonder-first·🤯spark)은 입구로 유지하되 **본문은 전문가급 정밀·정확**. 용어는 첫 등장 시 정의(terms).
- foot 라벨 = "심화·전문가 수준".

## 3. 구조 (Nick의 3기둥 = 3부작 허브 추천, finance 패턴)
`tracks/sports/` = 랜딩 + 3 에피소드. (대안: 단일 SPA 12정거장 — §8 Q)
```
tracks/sports/   (랜딩: "축구로 읽는 세계")
├── history/   축구의 탄생과 세계화
├── leagues/   빅리그의 시스템 (현재)
└── world/     빅리그 밖 — 세계의 축구
```

### Part 1 — history (축구의 탄생→세계화) ~6정거장
1. 기원: 공놀이는 어디에나 있었다(중국 cuju·중세 민속축구) → **왜 잉글랜드가 종주국?**(1863 FA, 규칙 통일)
2. 규칙의 탄생: 오프사이드·11명·90분·페널티킥은 왜 생겼나(호기심 폭발 지점)
3. 노동계급의 게임 → 프로화: 아마추어 vs 프로, 클럽의 탄생
4. 국제화: FIFA(1904)·첫 월드컵(1930)·유러피언컵→챔피언스리그
5. TV가 바꾼 축구: 중계권의 폭발(1990s~)·**보스만 판결**(1995, 이적 자유화)
6. 전설과 글로벌 아이콘(역사적): 펠레·마라도나·… 축구가 세계어가 되다

### Part 2 — leagues (빅리그의 시스템) ~6정거장
1. **승강제(promotion/relegation)와 리그 피라미드** — 왜 미국 스포츠엔 없나(개방형 vs 폐쇄형)
2. **5대 리그 비교(compare 블록)**: EPL(중계권·글로벌 상업화)·라리가·분데스(50+1·팬소유·관중)·세리에A·리그앙(육성)
3. 이적시장: 이적료·에이전트·셀링/바잉 클럽·유스 보상금·이적기간
4. 돈의 구조: 중계권 분배·스폰서·매치데이 / 구단 소유(연고팬 vs 미국자본 vs 국부펀드)
5. **FFP(재정 페어플레이)**와 논쟁 + **유러피언 슈퍼리그 시도·무산(2021)**
6. 유럽 대항전(챔스·유로파)과 계수, 클럽 vs 국가대표

### Part 3 — world (빅리그 밖, 세계의 축구) ~6정거장
1. 남미(브라질·아르헨티나): **유망주 수출 모델**·코파 리베르타도레스·동네축구→세계
2. 아프리카: 인재 유출입·유럽 진출 경로·네이션스컵
3. 아시아: J리그(지역연고 장기구상)·K리그·중국(거품과 붕괴)
4. 중동·신흥 자본: 사우디 프로리그·**스포츠워싱 논쟁**(투자·성장 vs 인권 세탁) — 균형
5. 북미 MLS: 프랜차이즈·드래프트·샐러리캡·**승강제 없음**(유럽과 정반대 모델)
6. 유스·데이터·그늘: 아카데미(라마시아 등)·스카우팅·xG/데이터분석 / FIFA 부패·매치픽싱·참사(힐스버러→안전개혁)·여자축구 부상

> 합 ~18정거장. 단일 SPA면 각 기둥 4개로 압축해 ~12.

## 4. 호기심 앵커 (예)
왜 11명·90분·오프사이드? / 50+1 규칙이 뭐길래 / 승강제 없는 미국의 폐쇄리그 / 이적료 1000억의 정체 / **FIFA 회원국이 UN보다 많다** / xG(기대득점)란 / 보스만 한 선수가 축구 경제를 바꾸다.

## 5. ⚠️ 시각 자산 — 이 트랙의 최대 난점
축구 사진 대부분이 **저작권(게티 등)**. 선수 액션샷·구단 로고/엠블럼(상표)은 **사용 불가**. 전략:
- **PD/CC만**: 초기 축구 판화·1900년대 흑백사진·역사적 월드컵 PD·**경기장 외관(CC 다수)**·트로피·팬문화·전술 포메이션 다이어그램(자체 SVG/설명).
- **차트 적극 활용**(데이터 충격): 구단 수입(Deloitte)·역대 최고 이적료 추이·리그 중계권 규모·관중수·5대리그 매출 비교. → chart 블록이 '시스템·돈' 설명의 주력.
- 라이선스 파일 일치·전점 Read 검수(기존 규칙). 헤드리스 Chrome 렌더 확인.

## 6. 안전·균형
- **스포츠워싱·부패·참사·이주노동(카타르)**: 사실·균형으로 포함(고등/일반엔 오히려 좋은 비판적 소재). 선정·단정 회피, "이런 시각/저런 시각".
- **베팅 조장 금지**(매치픽싱은 '문제'로만 다룸).
- 생존 선수/구단주: 우상화 금지·역할/시스템 중심, 저작권 사진 회피.
- 참사(힐스버러 등)는 존엄하게 — '안전 개혁의 계기'로.
