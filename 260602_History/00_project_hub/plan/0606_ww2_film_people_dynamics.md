# 0606 — 세계대전(ww2) 심화: 영화 · 인물 · 역학관계

> Nick 방향 전환을 반영한 ww2 에피소드 심화 설계. 핵심: **단일 영웅 카드를 넘어, "감성(영화)→인물(빛과 그림자)→구조(역학관계)"로 깊이를 한 단계씩 올린다.**
> 진행 순서(합의): **(a) 영화 연계 → (인물 카드) → (b) 한국전쟁 역학관계도.** 인라인 직접 진행(멈춤 없는 workflow, CLAUDE.md §프로토콜).

## 0. 왜 이 방향인가
- 안네가 "정서적 입구"였듯, **영화는 중1이 역사에 빠져드는 가장 강한 입구**다(이야기·인물·감정).
- 한 명의 영웅보다 **관계와 구도**를 보여주면 "왜 이런 일이 일어났나"의 진짜 답에 닿는다(특히 냉전 대리전=한국전쟁).
- 모든 인물은 **빛과 그림자**. 가해/피해의 단순 이분법을 깬다(쉰들러, 이오지마 일본군).

## 1. 표현 3형식 (엔진 블록)
1. **영화 연계 카드 (`movies`)** — 신규 블록. 제목·연도·감독·**실존 인물/사건**·**중1 적합성 신호등**·"왜 볼 만한가"·**실화 vs 각색** 한 줄·예고편/공식 링크.
2. **인물 카드 (도감 v2, 기존)** — people.json 확장 + 에피소드 people[]에 slug → 도감 상세 양방향.
3. **역학관계도 (`relations`)** — 신규 블록. 두 진영(색)·구성원(역할)·**긴장선(tension)**. 한국전쟁 전용으로 설계하되 재사용 가능.

## 3. 신규 엔진 블록 스펙
### 3-1. `movies` (영화 연계 카드)
```jsonc
"movies":[{
  "title":"쉰들러 리스트", "year":"1993", "director":"스티븐 스필버그",
  "basedOn":"오스카 쉰들러 (실존)", "slug":"oskar-schindler",   // 있으면 도감 링크
  "fit":"yellow",                 // green=전체 / yellow=부모와 함께 / red=클립·맥락만
  "why":"가해자 진영의 사업가가 1,100여 명을 구한 실화 — '빛과 그림자'를 가장 깊이 보여준다.",
  "realVsFiction":"실화 기반. 인물·구출은 사실, 일부 장면은 극적 각색.",
  "link":{"label":"예고편(공식)","url":"https://..."}   // 검증된 URL만
}]
```
- 렌더: 카드 + 신호등 배지(🟢/🟡/🔴) + "실화 vs 각색" 줄 + 외부 링크(`target=_blank rel=noopener`).
### 3-2. `relations` (역학관계도)
```jsonc
"relations":{
  "title":"한국전쟁, 왜 세계가 끼어들었나",
  "sides":[
    {"label":"공산 진영","color":"red","members":[
      {"name":"스탈린","role":"소련 — 남침 승인·무기 지원(배후)"},
      {"name":"김일성","role":"북한 — 남침 주도","slug":""},
      {"name":"마오쩌둥","role":"중국 — 인민지원군 참전"}]},
    {"label":"자유 진영","color":"blue","members":[
      {"name":"트루먼","role":"미국 대통령 — 제한전 결정"},
      {"name":"이승만","role":"대한민국 대통령"},
      {"name":"맥아더","role":"UN군 사령관 — 인천상륙·확전 주장→1951 해임"}]}
  ],
  "tensions":[
    {"a":"트루먼","b":"맥아더","label":"제한전 vs 확전(만주 폭격·핵) → 해임. 문민통제의 고전 사례"},
    {"a":"스탈린","b":"마오","label":"누가 부담을 질 것인가 — 소련은 배후, 중국이 피를 흘림"}
  ]
}
```
- 렌더: 좌우(또는 상하) 두 진영 색 패널 + 구성원 칩 + 가운데 긴장선 콜아웃. 바닐라 CSS(그래프 라이브러리 X).

## 4. 수위 정책 (★중1 — APP_PRINCIPLES 준수)
- 추천 영화 대부분 **15세+**(폭력·일부 선정). **신호등으로 명시**: 🟢전체 / 🟡부모와 함께 / 🔴핵심 클립·맥락만.
- 앱은 **영화를 틀지 않는다**. 예고편/공식 링크 + "왜 볼 만한가" + 함께 보기 권유. 잔혹 장면은 글로 완충.
- 「이오지마에서 온 편지」=적의 인간화(균형) 의도 명시.

## 5. 창의 장치 (NCC 제안 — 계속 추가)
- **C1. "실화 vs 각색" 한 줄** = 미디어 리터러시. 영화를 *비판적으로* 보게 한다.
- **C2. 양쪽의 눈(페어링) 모티프** — 앱 전체 관통: 안네↔쉰들러(피해자↔구원자), 사다코↔오펜하이머(당한 자↔만든 자), 미군↔일본군(이오지마). "역사엔 늘 두 눈이 있다."
- **C3. 역학도 노드 클릭 → 도감** (slug 있으면) — 구조에서 인물로 드릴다운.
- **C4. "그 총성이 없었다면?"** — 페르디난트 암살에 reflect/choice 연계(우연이 역사를 바꾼다).
- **C5. 신호등 = UI 언어로** — 영화·수위·확신도를 색으로 통일(🟢🟡🔴).

## 6. 실행 순서 & 게이트
- **A. movies 블록** — 엔진 추가 → 영화 4편 데이터(+예고편 URL **실제 200 검증**) → 빌드/JS_OK → 배포 → 라이브 검증.
- **P. 인물 카드** — people.json에 페르디난트/프린치프·쉰들러·슈필만·오펜하이머(+사다코 검토) 추가, 이미지(Wikimedia 출처검증), 에피소드 people[]에 slug → 양방향. 빌드/배포.
- **B. relations 블록** — 엔진 추가 → 한국전쟁 역학 데이터 → 빌드/JS_OK → 배포 → 라이브 검증.
- 각 단계: **인라인 직접 진행**(병렬 hang 금지), 매 스텝 가시 리턴, 실측 보고. 시스템(EPISODE_SCHEMA·PROGRESS·skills) 동반 갱신.
