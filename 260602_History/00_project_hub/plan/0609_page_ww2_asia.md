## 2. 🎨 비주얼
- **image(배열)**: ① 일제강점기 조선(서울/경성 또는 신사참배·공출) PD — **수위 절제**(잔혹 직접 묘사 회피) ② 독립운동(3·1운동·임시정부) PD.
- **people(신규 ★)**: **안중근**(도감 확장 1순위) + 가능 시 **윤동주**. 카드 + 도감 페이지(역링크).
- **voice**: 징용·근로정신대 끌려간 청년/소녀(✍️상상, 수위 주의 — 고통은 암시·존엄 중심).

## 3. 📚 deepdive
- **식민지 동원 체제**: 1938 국가총동원법 → 조선 인적·물적 수탈(징병·징용·공출·창씨개명).
- **강제징용·강제동원(★)**: 사실관계 + 현재 한일 외교 쟁점(절제·균형).
- **대동아공영권의 허구**: "아시아 해방" 명분 vs 식민 지배 실제.
- **저항의 역사**: 의병 → 3·1운동 → 임시정부 → 무장 독립운동(안중근·윤봉길) → 광복군.
- **역사 논쟁**: 식민지 근대화론 vs 수탈론 (양측 논거 균형 제시, 중1 입구는 감정 강요 회피).
