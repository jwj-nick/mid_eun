# tracks-write — 분야 트랙 콘텐츠 작성 (고등/일반 수준)

> **이 스킬은 `hist-content-write`(시간축 허브, 中1 딸용)와 다르다.** 분야 트랙(`tracks/sci-tech` 등)의 "workflow 담당". 엔진/스키마(`build.py`, `episode.json`)는 공유하되 **콘텐츠 모델·대상·문체·심화 방식이 다르다.** (Nick 0615 #3 지시)

## 0. 대상·목적 (history와의 결정적 차이)
- **대상 = 고등학생·일반인.** 中1 아님. 中1 과학 수준은 너무 낮아 이 트랙엔 부적합.
- **목적 = 분야사(과학기술·예술·문화·체육·금융 등)에 흥미를 갖고 지식·지평을 넓히기.** '발명·발전이 오늘의 당연함을 만든 과정'을 호기심으로 따라가고, 학교 교과(분야에 맞게: 과학·통합사회·경제·역사·음악·미술 등)와 자연스럽게 잇는다.
- **문체 = 교양서 평서체(~다/이다) + 엣지.** 친근 반말 금지. 정확하되 읽기 좋고, 호기심을 깨우게.

## 1. 콘텐츠 모델 (★ history와 다른 핵심)
> **★ 0순위 — 호기심 엔진(wonder-first). 0617 전(全) 분야 트랙 표준으로 승격.** 통사·연대기 나열은 금지(평이·엣지 없음). 각 정거장은 **"오늘 너무 당연한 것이 그 전엔 존재하지 않았다, 상상이 가니?"** 로 독자의 호기심을 깨운다. 정거장당 **장치 ≥3**: ①🤯 그 전엔 없었다(낯설게) ②🔍 일상 속 숨은 원리 ③🌀 상식 뒤집기(mind-bender 1) ④❓ 만약 없었다면(주로 reflect) ⑤📊 숫자의 충격. **hook은 경이/도발로 연다(날짜·인물 나열 X)**, 짧고 센 문장 + 직접 호명. 정거장당 🤯 `spark` 블록 1개 필수. (과학 특화판 = `sci-content`; 그 외 분야는 이 스킬.)

1. **처음부터 높은 수준.** "쉬운 본문 + 더 깊이 펼치기(같은 목표 수준)" 같은 레벨링 접이식 `deepdive`는 **쓰지 않는다.** 본문 자체가 고등/일반 수준이어야 한다. (동어반복 금지 — Nick 지적)
2. **학교 교과와 자연 연결.** 각 정거장이 고등학교 과학(물리·화학·생명과학·지구과학)의 어떤 단원·개념과 닿는지 본문에서 자연스럽게 짚는다. 예: 전기·통신 ↔ 물리 전자기, 화학·물질 ↔ 화학 주기율·결합, 원자·우주 ↔ 물리 현대물리, 의학·생명 ↔ 생명과학 유전. 짧은 "📚 교과 연결" 한 줄을 프로즈로(별도 필드 X).
3. **외부 심화는 링크로.** 더 깊이 가고 싶은 독자를 **위키백과·권위 자료(Khan, 공식 기관, 표준 문서 등)로 자연스럽게 연결**한다 → `links` 블록(아래). 앱이 모든 깊이를 품으려 하지 말고, 신뢰할 좋은 길을 안내한다.
4. **도메인 전문가 검수.** 기술적으로 깊은 트랙(특히 sci-tech의 코덱·반도체·NPU)은 작성 후 **해당 분야 전문가(Nick) 검수**를 배포 전 게이트로 둔다.

## 2. 블록 사용 (트랙 프로파일)
- **사용:** `hook`(경이/도발 장면) · **`spark`(🤯 '그 전엔 없던 세상'+상식뒤집기 콜아웃 — 정거장당 1, 필수)** · `why`(개념의 의의) · `lens`(그때의 사고·논쟁·맥락) · `cards`(정확한 사건·인물·메커니즘) · `timeline` · `connect`(트랙 줄기 잇기) · `image`(≥2, PD/CC) · `chart`(지표·통계) · `compare`(단계 전환) · `choice`(윤리·쟁점) · `quiz`(개념형) · `reflect`(사고 확장·만약 없었다면) · **`links`(외부 심화)**.
- **`spark` 블록 스펙:** `spark:{ icon?, title, body, mind? }` → 🤯 강조 콜아웃. `body`='그 전엔 없던 세상'·counterfactual, `mind`=상식 뒤집는 한 줄. order에서 hook 직후 배치.
- **미사용:** `deepdive`(레벨링용 접이식 — 트랙에서는 쓰지 않음). *예외:* 본문에 넣기엔 길지만 같은 고등/일반 수준의 '보충 사실'이 꼭 필요하면 최소한으로만. 기본은 본문+links.
- **`links` 블록 스펙(신규):** `links:[{label, url, source, note?}]` → "🔗 더 깊이 알아보기" **항상 표시 목록**(접이식 아님). 위키백과(ko 우선, 필요 시 en) + 권위 자료. **모든 URL은 실제 200 검증 필수**(죽은/추측 링크 금지). `target=_blank rel=noopener`.

## 3. 절차
1. **리서치:** 표준 통설 + 1차/권위 자료 링크 후보 수집(`20_research/tracks-<slug>/`). 교과 연결 지점 메모.
2. **본문 작성:** 고등/일반 평서체로 hook→why→lens→cards→timeline→connect. 교과 연결 한 줄 자연스럽게.
3. **외부 심화 링크:** `links` 블록 — 위키백과 등 200 검증 후 등재.
4. **이미지:** 정거장당 ≥2 (재사용+신규, 전점 Read 검수, PD/CC) — `hist-visuals` 절차 공유.
5. **빌드:** `python 40_build/build.py tracks/<slug>`.
6. **검수:** 사실 정확성 + 고등/일반 수준 적정 + 교과 연결 자연스러움 + 외부 링크 200 + (전문 영역) **전문가(Nick) 검수**.
7. **배포:** `cp` → deploy repo → push(단독·최소) → G3 라이브 폴.
